# LiSA-GS 方法介绍（简体中文）

**LiSA-GS：面向可重光照高斯泼溅的光源空间神经传输图集**
*Light-Space Neural Transport Atlases for Relightable Gaussian Splatting*

- 工程代号：PORT-GS 中的表示 `light_atlas`（最终配置 `--material-head svbrdf`）
- 提出日期：2026-10-01；六场景验证完成：2026-10-02

## 0. 一句话概括

**LiSA 从光源视角把 3D 高斯“泼溅”成一张可学习的“光通量图集”，场景中每个可见像素再到这张图集的多尺度金字塔上查询，
同时得到阴影、半透明/次表面散射和近邻反弹光。整个系统端到端可微，不需要任何预训练模型或外部先验。**

---

## 1. 研究任务

- **输入**：一个物体的多视角照片，每张照片只由一个已标定位置的点光源照亮（OLAT，One-Light-At-a-Time）。
- **输出**：在**新视角 + 新点光源位置**下渲染出逼真的图像（novel-view relighting）。
- **难点**：要同时正确表现
  1. **投射阴影**（cast shadow），尤其是落在大面积表面（如地板）上的锐利阴影边缘；
  2. **半透明与次表面散射**（translucency / subsurface scattering, SSS），如玉石、树脂、蜡、皮肤的“透光感”；
  3. **高光与材质**（specular / material），以及近处表面之间的**间接光**。

---

## 2. 我们在现有方法中观察到的问题

在六个场景上逐张检查现有方法（SSD-GS、GS³、RNG，以及 PORT-GS 中已有的三种方法）误差最大的测试图，得到两个核心观察：

**问题一：阴影是“每个高斯一个值”。**
GS³、SSD-GS 和 PORT 已有方法都为**每个高斯**算一个可见度（visibility），再当作属性泼溅到图像上。
一个覆盖大片地板的高斯只有一个可见度值，因此**阴影边界无法穿过它**，结果是阴影缺失或被抹糊；
PORT 默认方法的 64 层深度阴影体（deep-shadow volume）还会带来深度量化误差。

**问题二：次表面散射是“局部”的。**
SSD-GS、SSS-GS 的 SSS 模块都是**逐高斯的局部 MLP**（根据光照和视线方向预测偶极子参数或散射辐射）。
但半透明的本质是：**物体其他位置吸收的光，会在内部传播后从这里射出**。局部着色根本“看不到”别处沉积的光，所以透光感表达不足。

---

## 3. 核心洞察：一张光源空间图可以同时解决三件事

对强度为 `I` 的各向同性点光源，被照亮表面的“辐照度 × 面积元”恰好等于光源的立体角元：

```
E(x) · dA(x) = I · cos(θ_i) / r² · dA = I · dω
```

也就是说：**从光源看过去，每个纹素（texel）携带的入射光通量都一样，都是 `I·dω`，与表面法线和距离无关。**
如果我们从光源位置用普通的 alpha 合成去“泼溅”高斯，高斯 `i` 得到的合成权重 `T_i·α_i` 恰好就是它接收到的光通量份额。

由此，三种光传输现象都可以写成**对同一张光源空间图的“聚集”（gather）**：

| 现象 | 物理含义 | 在光源空间图上的操作 | 对应经典方法 |
|---|---|---|---|
| 阴影 | 接收点沿光线方向前面有没有东西挡住 | 读取该光线上沉积光通量的**深度分布** | 阴影贴图 / 矩阴影贴图（Moment Shadow Maps） |
| 次表面散射 | 别处吸收的光在体内传播后射出 | 用依赖接收点的**核**对沉积光通量做**卷积**：横向是光源空间模糊，纵向是厚度衰减 | 半透明阴影贴图（Translucent Shadow Maps）、高斯和扩散剖面 |
| 近邻反弹 | 附近被照亮表面再照亮这里 | 在同一张图上做**更大尺度**的聚集 | 反射阴影贴图（Reflective Shadow Maps） |

**经典方法把“存什么”（深度、辐照度）和“怎么聚集”（PCF 滤波核、偶极子核）都手工固定。**
LiSA 的做法是：
- **存什么 → 学出来**：每个高斯泼溅的是**可学习的光通量特征**；
- **怎么聚集 → 学出来**：在**多尺度金字塔**上，用**依赖接收点的可学习核**来聚集；
- 全部通过可微光栅化**端到端训练**。

**额外好处（光源泛化）**：图集对每个光源位置都重新渲染，而网络只看“相对于光源”的量（深度偏移、厚度、沉积通量），
因此传输算子对光源移动是“等变”的。对新光源的泛化来自结构本身，而不是靠把光源坐标当输入去插值。

## 4. 方法细节

整体输出公式（`E = I / r²` 为接收点处的入射辐照度尺度）：

```
L = E · [ V · ρ  +  Σ_k Σ_c W_{k,c}(x) · Φ_{k,c} ]
          └局部┘     └────── 光源空间传输 ──────┘
```

- `ρ`：局部神经材质（直接光照下的反射）
- `V`：逐像素可见度（阴影）
- `Φ_{k,c}`：第 `k` 层金字塔、第 `c` 个通道上聚集到的光通量特征
- `W_{k,c}`：可学习的非负传输核权重

注意：**输出对聚集到的光通量是线性的**。这相当于一个“光源空间的预计算辐射传输（PRT）”或“神经 BSSRDF”；
经典的高斯和半透明阴影贴图正是它的一个特例（只有一个通道，衰减核固定）。

### 4.1 场景表示

- 标准 3D 高斯（位置、尺度、旋转、不透明度），使用 gsplat 的自适应致密化（densification）；
- 每个高斯额外携带：基础颜色 `b_i`、32 维潜在材质编码 `f_i`；
- 法线取高斯协方差的最短轴；
- 真实场景沿用 PORT-GS 的训练相机旋转校正（协议不变，测试时使用原始标定）。

### 4.2 光源通道：神经光通量图集（Neural Flux Atlas）

- 对每个光源位置，放一台**从光源看向场景中心的透视相机**；视场角覆盖 99.9% 高斯的投影范围（对漂浮噪点稳健），上限 75°。
- 每个高斯输出光源空间通道：

  ```
  c_i = [ φ_i , z_i , z_i² ],   φ_i = softplus( E_θ(f_i, b_i, |n_i · l_i|) ) ∈ R^8
  ```

  其中 `z_i` 是以物体半径归一化的光源空间深度。
- 一次 gsplat 光栅化（512×512）得到：
  - 沉积光通量特征 `Φ = Σ T_i α_i φ_i`（8 通道）
  - 覆盖率 `M0 = Σ T_i α_i`
  - 深度一阶矩、二阶矩 `M1, M2`

### 4.3 多尺度金字塔

对图集做 7 层高斯金字塔（二项式模糊 + 2 倍下采样，512 → 8），对应从约 1 个纹素到约物体 1/3 大小的世界尺度。
小尺度负责锐利阴影，大尺度负责次表面散射和近邻反弹。

### 4.4 延迟式接收点聚集（Deferred Receiver Gather）

1. 从相机光栅化得到每个像素的“接收点”：世界坐标（由期望深度反投影）、材质编码、基础颜色、法线；
2. 把接收点投影到光源空间 `(u, v, z)`，在每一层金字塔上双线性采样；
3. 每层 `k` 计算统计量：
   - 覆盖率 `M0_k`、沉积深度均值 `μ_k`、扩展度 `s_k = sqrt(var_k + τ_k²)`（`τ_k` 为该层纹素大小）
   - 深度偏移 `δ_k = z − μ_k`（即“在被照亮表面之后多深”，相当于厚度）
   - 归一化偏移 `t_k = δ_k / s_k`
   - **矩阴影检验** `V_k = 1 − M0_k · Φ_N(t_k − 3)`（`Φ_N` 为标准正态分布函数，3σ 偏置用于抑制自阴影瑕疵）

**关键区别**：可见度是**逐像素**计算的，不再是逐高斯。一个很大的地板高斯上也可以出现清晰的阴影边界。

### 4.5 神经延迟着色（三个小网络）

**(a) 局部神经材质 `ρ`（最终采用 `svbrdf` 头）**
- 输入：潜在编码、法线、光线/视线/半程向量/反射向量的方向编码、各种余弦，以及一组球面高斯高光提示
  `exp(κ(n·h − 1))`，`κ ∈ {8, 32, 128, 512, 2048}`；
- `svbrdf` 头的结构：

  ```
  ρ = softplus( b + m_0 + Σ_{j=1..8} s_j(f, enc(x)) · m_j )
  ```

  `m_j` 是**不含位置**的方向网络输出（8 个随光照变化的基响应），`s_j` 是**与光照无关**的位置系数。
- 设计目的：**限制局部项的位置自由度**，避免它把阴影和次表面散射“偷偷背下来”，让阴影留在 `V` 里、透光留在传输项里，分解更符合物理。

**(b) 矩可见度 + 神经残差 `V`**

```
V = sigmoid( logit(V_0) + g(多尺度统计量, f, n·l) )
```

`g` 零初始化，因此训练从经典矩阴影检验出发，再学习半影、偏置以及毛发等的透射。

**(c) 光源空间传输核 `W`**
一个 MLP 根据接收点编码和每层统计量，输出非负权重 `W ∈ R^{7 × 3 × 8}`（层数 × RGB × 通量通道），与聚集的通量线性组合。

### 4.6 训练

- 损失：显示域 0.8·L1 + 0.2·D-SSIM，外加 0.05 的 alpha 掩码 L1；
- 30k 步，seed 0；前 2000 步只用局部项 `L = E·ρ`，之后打开光源通道（阴影 + 传输）；
- 光源通道的梯度会回传到高斯的几何、不透明度和编码——**阴影和透光也反过来帮助优化几何**；
- 单场景约 18–25 分钟（RTX 6000 Ada，1,066–1,514 秒）。

### 4.7 计算开销

每个光源只多 1 次 512² 光栅化（约 10 通道）、1 个 7 层金字塔、每像素 7 次双线性查询和 3 个小 MLP。
它**替代**了原来的 64 通道深度阴影体，实际训练比逐高斯深度阴影版本**快约 1.35 倍**。
**无需新增 CUDA 代码**（gsplat 光栅化 + `grid_sample` + MLP）。

## 5. 与相关工作的区别

| 相关工作 | 它的做法 | LiSA 的不同 |
|---|---|---|
| RNG（CVPR 2025） | 仅深度的阴影贴图，每像素一个标量提示，MLP 解码 | 泼溅**可学习通量特征 + 深度矩**，多尺度聚集，并建模半透明/反弹 |
| GS³（SIGGRAPH Asia 2024）、SSD-GS（ICLR 2026） | 逐高斯朝光源泼溅求阴影，再用 MLP 修正 | **逐像素（延迟式）可见度**，单个高斯内也能有阴影边缘 |
| SSD-GS、SSS-GS（NeurIPS 2024） | 逐高斯的局部 SSS（偶极子参数或 MLP） | **非局部、考虑厚度**的光源空间传输，对沉积通量线性 |
| 半透明/反射阴影贴图（2003/2005）、d'Eon & Luebke（2007） | 解析核、存储辐照度、几何已知 | 通量特征和核都**可学习**，通过高斯做**逆渲染** |
| Neural Shadow Mapping（2022）、KPNSM（2025） | 屏幕空间 CNN，几何已知 | 光源空间聚集，无屏幕空间 CNN，几何与材质联合优化 |
| Deep Gaussian Shadow Maps（2026） | 高斯的经典透射率图集，无学习 | 可学习特征 + SSS/反弹 + 神经修正 |
| RenderFormer、DiffusionRenderer、TRON | 大规模预训练神经渲染器 | 逐场景优化、物理结构明确、**无需预训练** |

**主张的三点贡献：**
1. 把点光源光传输**重参数化到光源空间**，并为高斯泼溅设计了与法线无关的**可学习光通量图集**；
2. **多尺度接收点聚集**，传输核对通量线性——可理解为“可学习的半透明阴影贴图 / 光源空间 PRT”；
3. **基于矩的延迟式高斯阴影 + 神经残差修正**。

**不主张：** 物理精确的 SSS 参数；光源看不到的区域经多次反弹后的全局光照；环境光照重光照。

## 6. 实验结果

### 6.1 实验设置

- **六个场景**：真实 Real_NRHints（Cat、Pixiu）、合成 Synthetic_GS3（AnisoMetal 各向异性金属、Translucent 半透明）、
  合成 Synthetic_SSS-GS（bunny_small、dragon_small）；
- 全部官方训练集、**全部 1,937 张官方测试图**，使用最后一个检查点，测试时不做任何拟合；
- 指标：PSNR↑ / SSIM↑ / LPIPS↓（VGG）。

### 6.2 主结果（六场景平均）

| 方法 | PSNR ↑ | SSIM ↑ | LPIPS ↓ |
|---|---:|---:|---:|
| **LiSA（最终配置，svbrdf 头，30k 步）** | **31.367** | **0.9353** | **0.0630** |
| PORT directional_port_v1（30k 步） | 30.578 | 0.9316 | 0.0704 |
| PORT surface_attention（30k 步） | 29.974 | 0.9312 | 0.0701 |
| SSD-GS（100k 步） | 29.541 | 0.9115 | 0.0787 |
| GS³（100k 步） | 28.939 | 0.9106 | 0.0856 |
| RNG（30k+70k 步） | 27.947 | 0.9109 | 0.1075 |

逐场景 PSNR：

| 场景 | LiSA | PORT 默认 | SSD-GS | GS³ |
|---|---:|---:|---:|---:|
| Cat | 25.20 | 25.26 | 18.00 | 19.12 |
| Pixiu | 26.28 | 26.32 | 23.40 | 23.72 |
| AnisoMetal | 27.60 | **28.26** | 28.00 | 27.51 |
| Translucent | 31.04 | 29.32 | 31.99 | **32.76** |
| bunny_small | **40.16** | 38.17 | 38.48 | 34.42 |
| dragon_small | **37.92** | 36.14 | 37.38 | 36.11 |

**解读：**
- 六场景平均 PSNR/SSIM/LPIPS 三项均为最好；
- **增益集中在诊断所预测的地方**：相对 PORT 默认方法，Translucent +1.72 dB（82% 的视图更好）、bunny +1.99 dB（91%）、dragon +1.79 dB（97%）；
- bunny、dragon 超过训练步数多 3 倍多的 SSD-GS（+1.68 / +0.55 dB）；
- GS3 场景的地板阴影清晰且位置正确。

### 6.3 消融实验（六场景平均 PSNR）

| 变体 | 平均 PSNR | 变化 |
|---|---:|---:|
| 完整 LiSA（spatial 头） | 31.459 | — |
| 去掉光源空间传输 | 30.797 | −0.66（bunny −2.67） |
| 改回逐高斯可见度 | 31.351 | −0.11，且训练慢约 1.35 倍 |
| 只用经典矩检验，不加神经残差 | 31.283 | −0.18（bunny −0.87） |

分解探针显示：在次表面散射/毛发类材质上，**光源空间传输项贡献了 30%–49% 的辐射亮度**；在金属上只有约 9%——符合物理直觉。

### 6.4 新光源泛化（最有说服力的证据）

官方测试集的光源离训练光源只有 0–2°，所以它其实测不出“新光照”下的泛化能力。我们额外做了**留出光照**实验：
把整组 30° 范围内的光源（约 10% 训练帧）从训练中拿掉，只用于评估（新颖度中位数 4–11°、最大约 16°）。

| 场景 | PORT 默认 | LiSA（svbrdf） | 差值 |
|---|---:|---:|---:|
| AnisoMetal | 28.25 | 28.22 | −0.03 |
| Translucent | 27.93 | 29.48 | **+1.55** |
| bunny_small | 35.46 | 37.99 | **+2.53** |
| dragon_small | 34.73 | 37.49 | **+2.76** |
| 四场景平均 | 31.59 | 33.30 | **+1.70** |

在没见过的光照下，LiSA 的优势**保持甚至扩大**，AnisoMetal 上的劣势也消失了，SSIM 和 LPIPS 全部更好。
最终采用 `svbrdf` 头是根据**事先登记的规则**、只用留出光照数据决定的，没有看测试集。

## 7. 局限与下一步

**诚实说明的局限：**
1. **各向异性拉丝金属高光**仍偏弱：AnisoMetal 测试集比 PORT 默认方法低 0.67 dB（留出光照上持平）；
2. **侧光下的长阴影**：在 Translucent 上，光线与相机夹角 30–90° 时不如逐高斯阴影（掠射光会拉伸地板在图集上的纹素）；
3. Translucent 的 PSNR 仍低于 GS³ 和 SSD-GS；
4. 真实场景（Cat/Pixiu）的分数主要受测试相机位姿标定影响，LiSA 与 PORT 默认方法基本持平；对 SSD-GS/GS³ 的大幅领先主要来自 PORT 的相机自校正，而非 LiSA 本身；
5. 目前只有单一随机种子、六个场景；基线训练 100k 步而 LiSA 只训练 30k 步，尚未做等预算比较；
6. 单张透视图集要求光源位于场景外部（六个场景都满足）；光源看不到的区域经多次反弹才到达的光无法表示。

**下一步计划：**
- 在高斯切线坐标系中加入各向异性高光提示；
- 掠射光图集重采样（如变形/级联光源贴图）；
- 完整 18 场景基准 + 多随机种子；
- 与 SSD-GS / GS³ 做等训练预算（100k 步）比较。

## 8. 一分钟口头介绍稿

> 我们做的是基于 3D 高斯泼溅的点光源重光照：给定物体在不同点光源下的多视角照片，要在新视角、新光源下渲染出真实图像。
> 现有方法有两个共同问题：第一，阴影是每个高斯算一个值，大高斯上的阴影边缘会被抹掉；第二，半透明效果只靠局部网络，看不到别处吸收的光。
> 我们的观察是：从点光源看过去，每个像素承载的光通量完全相同。所以只要从光源方向把高斯泼溅成一张图，阴影、次表面散射和近邻反弹，
> 都可以变成在这张图上的“查询”。LiSA 让高斯在这张图上写入可学习的光通量特征，再让每个像素在多尺度金字塔上用可学习的核读取它们。
> 结果是：六个场景平均 PSNR 31.37，超过 SSD-GS 和 GS³；在没见过的光源位置上，比我们自己的强基线还高约 1.7 dB。
> 整个方法不需要预训练，也不需要新写 CUDA 代码，训练比原来的逐高斯阴影还快。
