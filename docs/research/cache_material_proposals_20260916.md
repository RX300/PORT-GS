# PORT-GS：神经光照缓存与神经材质改进建议

检索与代码核查日期：2026-09-16。状态：**研究提案，未实施、未实验验证、未替换当前方案**。
本次仅新增研究及自审文档；本页不是已接受的架构决策。

建议优先研究 **A：入光端与出光端分开的方向传输端口**，其次研究
**B：具有学习坐标系的局部 neural material**。先分别验证，再考虑组合。
两者都能沿用目前的 Gaussian、像素着色、点光源数据及 ssd-gs 环境。

## 1. 当前方案和实际证据

本次以工作区代码和最新方向化架构说明为准。部分旧文档仍保留历史架构，
不能把其中的“守恒 irradiance exchange”结论应用于当前版本。

- 当前为 `directional_port_v1`，R=512，B=4；B 是常数项和三个 spherical Gaussian。
- 源 Gaussian 与像素接收点调用同一个 `partition()`，共享端口中心及宽度。
- 共享 `direction_net` 从32维特征生成方向基；源端查询指向灯的方向，
  接收端查询指向相机的方向。它是材质条件化的潜在方向基，不是已标定的物理方向分箱。
- 每个端口有非负 RGB 4×4 矩阵；端口输出已经是最终非局部出射 RGB 的组成部分。
- 直接光是独立的 `165→128×4→3` MLP；输入已有灯方向、视方向、半角方向和位置编码。
- renderer 在 alpha 归一化后的属性和期望深度上着色，没有可靠表面法线、BSDF
  积分器或任意次级光线的路径追踪模块。

代码依据：[directional_transport.py](../../directional_transport.py)、
[transport.py](../../transport.py)、[renderer.py](../../renderer.py)。

最新完成的30k实验如下。这里列旧结果只用于提出假设，不用于选择新模型超参数。

表格最后一列是对 PORT 的判断，不是原论文结论。

需要区分三种对象：irradiance cache 存方向积分后的照明；incident-radiance cache
存某个入射方向的照明；PORT 的端口目前更接近**整体光传输算子的低秩中间状态**。
缓存整体传输适合其点光源重光照和半透明资产任务，但不会自动得到可编辑的物理材质。

## 3. 方案A：将一个空间端口改成一对“入光/出光端口”

### 3.1 解决什么问题

当前同一个空间核同时负责收集源和向接收点分发。
若希望把物体前侧的照明传到背侧，同一端口往往需要覆盖两侧；
扩大覆盖可能顺带混入周围不该参与的源或接收点。
这是当前参数化的结构性限制，尚未证明是具体场景的主导误差。

建议把每个隐含传输模式 r 改成两套空间支持：

- 入光端 `w_in(j,r)`：哪些 Gaussian 给该模式供光；
- 出光端 `w_out(x,r)`：哪些像素接收点读取该模式；
- 中间仍是现有的小型方向矩阵，连接同一编号的两个端点。

例如，一对端点可以分别集中在玉器的受光侧与背光侧，而不需要一个大球形核同时笼罩二者。
端点只是一个低秩模式的空间支持，不是可供光线相交的虚拟灯或真实散射点。
这里仍然有512个模式，而不是构造512×512个全连接传输模块。

```text
点光源
  ↓ 原可见性、逆平方衰减、入射方向
源 Gaussian → 入光端口 w_in → 端口方向矩阵 C
                                     ↓
像素接收点 ← 出光端口 w_out ← 方向传输状态
  ↓ 出射方向读取
非局部 RGB + 原直接光 → 原 alpha 合成与观察变换
```

### 3.2 明确计算

沿用当前质量权重 m、RGB exchange 比例 a，以及源照明量 E。
令 c 为颜色通道，j 为源 Gaussian，x 为像素接收点，r 为端口模式。

\[
\pi_{jrc}=\frac{m_j a_{jc}w^{in}_{jr}}
{\sum_t m_t a_{tc}w^{in}_{tr}},\qquad
Z_{rbc}(\ell)=\sum_j\pi_{jrc}b^{in}_{jb}(\omega_{j\ell})E_{jc}(\ell).
\]

\[
Y_{r,:,c}=C_{r,c}Z_{r,:,c},\qquad
L^{nl}_c(x,v;\ell)=a_{xc}\sum_r w^{out}_{xr}
\left[b^{out}(f_x,\omega_{xv})^T Y_{r,:,c}\right].
\]

\[
L_c=(1-a_{xc})L^{direct}_c+L^{nl}_c.
\]

第一版只拆分空间中心与宽度，仍用R=512、B=4、共享方向网络。
令输入/输出中心与宽度相同即可退回当前公式，便于检查改动的实际作用。
可以在初始化时复制两套空间参数；训练后允许它们独立移动。

E 沿用代码中“光强/距离平方×可见性”的约定，其中没有独立乘表面余弦。
m 是 opacity 与 Gaussian 尺度构成的归一化代理测度，不是已知表面积。
所以本方案不能通过归一化权重就声称物理能量守恒。

### 3.3 与近期工作的联系，以及保留的性质

这是受8DNA“入射端与出射端都重要”的启发对 PORT 做的低秩结构改动，
不是8DNA的复现。当前 PORT 本来就包含两端的空间与方向信息；新意在于
**解除两端空间支持绑定**，不能将它宣传为首次给 PORT 引入近场或方向传输。

保持分配、C、exchange 及出射基不依赖当前光强。多个灯的源注入 Z 可以相加，
再经过同一个线性传输算子。不要在聚合后的光信号后再接带偏置或非线性的 RGB MLP。
在固定几何与材质、alpha和观察变换之前，保留零光零输出与光照叠加性质。
这些是当前方案已有的优点，不作为新增贡献。

端口输出仍定义为最终的非局部出射光。**不能再整体乘一次接收点的原直接光
可见性或直接光材质网络**：前者会错误消除阴影内的非局部光，后者会改变上述语义。

### 3.4 改动、成本和训练

- 主要修改 `DirectionalTransport` 的两次空间查询；模型构造/配置保存记录两套参数。
  现有 renderer、数据合同和观察变换可复用。
- 当前每个端口一个3D中心和一个宽度；第一版额外增加512×4=2048个标量。
  仍以 `[N,R]` 和 `[M,R]` 矩阵汇总/读取，不构造全源—像素配对或五维巨型张量。
- 算子主阶仍为 O(N R B_in + M R B_out + R B_in B_out)，忽略固定RGB维。
  参数增量小不代表已经实测训练速度不变。
- 第一版保留直接光网络、exchange、C参数化及训练日程，使用现有多视图点光源RGB监督。
- 只有空间解耦有效后，再独立比较B=4与B=8；后者是方向容量消融，须报告新增参数和耗时。
  不在首次实验同时加入端口图网络、多尺度网格和新损失。

### 3.5 预期收益与自审结论

最有动机的对象是 Translucent、bunny_small 这类非局部传输明显的资产；
对Cat/Pixiu的收益不确定。风险是更自由的两端支持也更容易学习错误的跨区域漏光。
不能将两端之间的直线遮挡一律设为零，因为物体内部散射不要求该直线在空气中可见。

**结论：推荐作为第一候选，原因是改动小、对照清楚、适配现有数据；不是已证实的精度提升。**

## 4. 方案B：给直接光网络增加学习着色坐标系

### 4.1 解决什么问题

当前直接光网络已经是神经外观函数；再增加一个通用RGB MLP缺少明确理由。
它现在处理世界坐标中的方向。相同材质贴在不同朝向的表面时，共享网络需要自己
从特征中推断并补偿这种旋转。可以把这部分结构显式化，让有限容量用于拟合反射形状。

### 4.2 最小可实施版本

保留32维特征与现有直接光 MLP。增加一个小型共享 head，从材质特征预测两个3D向量，
正交化得到局部坐标系 Q。初始化为单位旋转。

\[
\widetilde\omega_l=Q_x^T\omega_l,\qquad
\widetilde\omega_v=Q_x^T\omega_v,\qquad
R_\theta=\operatorname{softplus}
\bigl(base_x+local(f_x,\operatorname{enc}(\widetilde\omega_l),
\operatorname{enc}(\widetilde\omega_v),\operatorname{enc}(\widetilde h),
\omega_l\cdot\omega_v,\operatorname{PE}(x))\bigr).
\]

其中半角方向也在同一局部坐标系中计算。仍令直接光为 E(x)×Rθ，
保持原维数的方向编码、位置编码及后续合成。
在Q为单位阵时可恢复现有直接光函数；端口分支使用原实现。
材质 head 不输入当前灯光RGB、图像编号或当前端口照明状态。

这借鉴 neural appearance models 的 learned shading frame，
不要求立即引入预训练大模型、mesh纹理UV或不同CUDA环境。
它明确只改直接光分支：当前已有的 `direction_net` 服务于非局部端口，并没有
给直接光 MLP 执行这个方向坐标变换。

### 4.3 后续材质化，以及不能越过的解释边界

若最小版改善留出灯光表现，再考虑把响应细分为宽角项与尖锐/各向异性项，
或在可靠表面区域引入解析材质底座及受限神经修正。这应是单独的第二阶段，
不能将GGX、fuzz、clearcoat和新cache一次性叠加后只报告总分。

NeuMatEx提供的重要提醒是：材质容量越强，越可能把照明误差吸收到材质里；
需要良好初始化与额外约束。PORT目前没有其预训练材质基、LMRM或独立不确定性估计。
本建议只迁移结构和优化原则，不宣称复用其完整系统。

第一版Q是**学习到的外观坐标系**，不等同于真实几何法线。
当前Gaussian的最短轴也不能无条件当作真实表面法线。由于特征在renderer中沿视线
进行alpha混合，像素特征和期望接收点还可能随视角改变；没有更可靠的表面对应前，
不能宣称获得了严格视角无关、可移植到路径追踪器的物理BRDF。

局部材质表示不能单独完成物体前侧到背侧的SSS；该部分继续由PORT非局部路径承担。
Cat的纤维轮廓和遮挡也不等价于局部neural material，不保证仅换材质就恢复毛发几何。

### 4.4 训练、成本与自审结论

- 先只增加Q预测和方向变换；相同训练图像、预算、阴影日程及Gaussian细化配置。
- 相同材质特征上共享坐标系预测器，不为每张照片学习一套旋转；用训练内留出灯光验证。
- 若进行固定几何/冻结端口的诊断，基模型必须只用fit子集训练，避免留出集提前进入几何。
- 首选 AnisoMetal 检查高光位置、宽度与方向插值，再看Cat/Pixiu的实际泛化。
- head开销及额外优化不稳定性需要测量；小网络仍应检查跨初始化波动。

**结论：适合作为第二个独立候选。若主要目标是金属高光，可先试B；
若主要目标是近场非局部重光照，优先A。它是有效外观建模改进，不是物理材质提取的保证。**

## 5. 为什么完整NIRC暂不列为首轮实施方案

真正的表面NIRC路线应明确计算

\[
L_o(x,v)=L_{direct}(x,v)+\int f_\theta(x,\omega,v)
\widehat L_i^{ind}(x,\omega;\mathcal L)
\max(n\cdot\omega,0)\,d\omega.
\]

这与“让一个MLP直接输出非局部RGB”不同。若要进一步使用两级Monte Carlo纠偏，
还需用独立路径样本估计真实积分与cache积分之差；样本分布、PDF与两项的目标量必须一致。
只增加一个图像loss残差，或者以当前网络自身预测当作真值，不能获得该无偏性质。
即使前向估计无偏，也不能直接推出逆渲染梯度或材质恢复无偏。

PORT当前缺少可靠表面法线、可积分的物理材质和次级路径采样器；半透明/纤维资产
还涉及表面BSDF之外的传输。增加这些模块属于另一项较大的架构研究。
已有代码里的光源阴影查询不等于具备完整路径追踪功能。

同样，直接把端口改成NIV式单个irradiance RGB会压掉各向异性与高光需要的方向信息。
可以把它作为未来低频子分支，但当前没有证据支持把整个非局部分支退化成这种表示。

## 6. 最小验证计划与淘汰条件

本节是后续实验建议，本次不执行训练。

1. **先选假设。** A1仅解耦入/出空间核；B1仅增加直接光坐标系。各自与当前模型比较，
   不混改端口数、训练时长、阴影和细化日程。使用官方train内部按灯方向分组的留出集。
2. **先验证属性。** A1在参数绑定时退回原公式；B1在单位坐标系时退回原直接光。
   检查零光零输出、相同光源强度缩放，以及多灯分别注入后相加。
   检查对象是线性前景，不能在gamma后或重复添加背景的图像上要求线性。
3. **再看泛化。** A在Translucent和一个真实场景；B在AnisoMetal和一个真实场景。
   用相同fit/validation分组和训练预算，看逐灯组PSNR/LPIPS及阴影、高光、轮廓误差。
   不按模型自己预测的“间接光区域”单独挑选优势样本。
4. **观察训练方差。** 初筛有明确收益后，再对候选及控制做少量匹配seed复验；
   报告结果范围及耗时，不只报告最佳一次。
5. **冻结后正式评估。** 选择与超参数确定后才进行六场景完整官方test评价；
   同时报告均值、最差灯组/视角、显存和每帧/每步耗时。

新增多灯/灯距扰动在没有GT时只是算子一致性或稳定性检查，不算真实重光照质量提升。
现有数据若缺少独立灯距变化，也不能据此声称近场外推成功。

若训练图像变好但留出灯光不改善，或新增能力主要表现为阴影漏光、亮斑漂移，
应淘汰该候选；不要继续以增加端口/方向数掩盖问题。
若主要误差仍集中在轮廓与期望深度混合，需要先重新定位几何/接收点瓶颈。

## 7. 建议的执行顺序

先验证A1；以B1作为另一条可独立解释的路径。A1与B1各自有效后才研究组合，
方向容量扩展和真正的物理NIRC放在后续。首轮可以完全留在PyTorch/gsplat及CUDA12.1栈内。

两条路线都与已有低秩传输、PRT和neural material思想有直接关系。
论文贡献是否成立，应由明确的算子差异、匹配预算的实验和未见灯光泛化共同支持，
不以“用了neural cache”或“参考最新论文”作为创新性依据。
