# LiSA改进提案：先解决几何覆盖与局部分支退化

日期：2026-10-03（JST）。**仅提案，全部未实施。** 用户要求先分析和给方案，本轮没有改模型、渲染器、训练损失、超参数或启动训练/消融。

[诊断证据](../experiments/full_dataset_analysis.md) · [SOTA判断](sota_assessment.md)

## 1. 目标与优先级

当前不是所有场景都弱：真实/SSS类别平均和总体SSIM/LPIPS已有优势。优先恢复少数系统性失败，保留光空间传输在bunny/dragon/candle上的收益；不建议首先推倒整个LiSA设计。

| 优先级 | 问题 | 首选改进方向 | 首轮验证场景 |
| --- | --- | --- | --- |
| P0-A | Lego/Drums几何向背景膨胀，早期占满点数 | 几何稳定阶段＋预算内高斯重分配，检查延迟接收点 | Lego、Drums；FurBall作防退化对照 |
| P0-B | 多场景V/rho近零、传输接管全部外观 | 稳定局部分支、分阶段开放传输、约束可见度残差 | CupFabric、soap；bunny作传输能力对照 |
| P1 | 金属、织物和小高光过暗/过宽 | 切线坐标系中的各向异性反射瓣与适度峰值监督 | AnisoMetal、Drums、CupFabric |
| P2 | 多层接收点、侧光长阴影与图集过滤 | 更可靠的接收深度、分层读取、按足迹选择尺度 | Translucent、Lego、Drums |
| 验证必需 | 尚无全面SOTA证据 | 统一GT、等预算、多种子、真正留出光照及近期baseline | 方案通过后完整18场景 |

## 2. P0-A：先解决几何与点数分配

### 依据

Lego/Drums对最强baseline分别低9.67/8.37 dB，全部400帧均落后。完整test alpha L1为0.109/0.046；均匀探针IoU均值仅0.771/0.783，异常主要是多覆盖背景。约2.9k/3.5k步即接近400k点上限。当前增密在无剩余容量时不能split，25k结束细化。

### 拟议机制

1. 给复杂几何一个更稳定的早期学习阶段：简化局部着色或采用受控的forward→deferred过渡，先形成可靠覆盖，再开放全部传输与高频外观。多光照图像不能简单当作固定光照RGB监督，应保留必要的光照条件。
2. 在相同400k上限内，为高误差、轮廓和大投影高斯保留细化机会：先回收低贡献/冗余高斯，再按有效误差与覆盖分配clone/split；区分真实高频与标定噪声。
3. 将轮廓、多视图一致性作为辅助约束的候选。已有alpha监督不足以避免覆盖膨胀，可在可靠硬表面区域加强约束；避免把透明/毛发边界强制变成不透明表面。
4. 对期望深度混合严重的像素，后续单独考虑主层或分层接收点；先不把这一较大渲染改动和增密改动同时加入。

### 最小验证

先在Lego/Drums的官方train内部固定留出相机/灯组。参考模型也按同一fit集合重训，不能将已有fit-all模型在其见过的帧上当成验证baseline。固定seed、30k、400k与其余损失，分别比较参考、仅预算重分配、仅早期几何阶段；只有单项都有效时再测试组合。检查留出PSNR/SSIM/LPIPS、alpha L1/IoU、误覆盖面积、点数/尺度分布和高斯分配过程。

对FurBall做同配置防退化检查。轮廓改善但PSNR下降，或轮廓被强制收缩而丢失毛发/透明边界，都不算成功。当前没有证据支持直接将所有场景上限升到1M。

### 成本与风险

主要增加训练时调度/统计，保持点数上限时不必增加最终推理容量；早期阶段若计入原30k预算会挤占外观学习时间。分层接收点会增加光栅化与着色成本，应独立评估。风险是将细化集中到噪声、错误阴影或透明边界上。

## 3. P0-B：恢复可训练的局部材质分支

### 依据

CupFabric、FurScene、Fish、soap、statue的均匀抽查帧中，传输承担约100%线性辐射；可见度残差将合理的矩检验先验压到近零，同时局部rho也很小。soap轮廓准确，但45,427个GT中性亮峰像素对应的预测亮峰仅4个。CupFabric也主要缺少杯面与织物高光。

### 拟议机制

1. 分阶段学习：先稳定局部漫反射/镜面与几何，再逐渐开放传输幅度及可见度残差；与现有2k同时开放设置作单变量比较。
2. 将局部响应参数化为稳定的非负材质分量，避免所有方向共享的输出整体进入softplus极负饱和区。使用可解释的漫反射/镜面基底与学习残差，是候选；不依靠硬编码给每张图加亮度。
3. 对可见度残差设置可调范围或相对于可靠几何先验的软约束，并随训练渐进放宽。只对可靠受光位置加约束；不要无条件将V拉到1，也不要将矩检验视为真实阴影标签。
4. 记录局部/传输能量、V与rho分布、分支梯度以及中间权重，定位首次退化时刻。完整输出仍维持对光强的线性约束。

不建议先给传输占比设置统一硬上限。candle/bunny本来需要较大传输贡献；Fish虽已退化仍有较好的本地PSNR，说明“提高局部比例”本身不是最终质量目标。

### 最小验证

在CupFabric/soap固定留出集上，先对“延后/渐进开放传输”和“限制早期可见度残差”分别测试，保持局部网络大小、几何策略和总步数一致；观察局部是否恢复、亮峰误差与留出光照成绩是否共同改善。bunny作为传输能力对照，防止只是抑制全部散射。

需同时记录最初1k/2k/5k及后续若干阶段的分解与梯度，但不得按官方test选择权重。若局部恢复但留出结果没有提升，应拒绝把分量比例改善当成性能改进。

### 成本与风险

日程/软约束的推理成本通常很小；材质参数化改变需重新训练，现有权重应保留。过强先验可能把真实多次散射或几何误差错误地压给局部材质，损害SSS优势。不能预先保证分支恢复的PSNR收益。

## 4. P1：补强方向性高光

### 拟议机制

在当前svbrdf头中增加基于稳定切线框架的各向异性SG或GGX提示，学习切线旋转和两轴宽度；保持位置只通过材质参数/系数进入，避免回到可直接记忆光照外观的位置大MLP。必要时单独比较8与更大数量的显式材质系数，不能把多个容量变化混成一个实验。

候选损失为训练图上的亮峰与局部对比度监督，或训练域的HDR/显示域混合约束；先对自然光照覆盖进行验证。不能通过提高曝光、只拟合饱和像素或改变test指标获得表面提升。

### 最小验证与取舍

在P0修复后的固定版本上，选AnisoMetal及Drums/CupFabric做同一留出光照比较，报告亮峰precision/recall、对比度、全图三指标与低亮区域误差。每次只加入一个提示/损失。增加少量材质参数和逐像素方向计算；切线/法线不稳定可能产生闪烁，过重高光损失可能牺牲整体颜色。

## 5. P2：接收点与阴影取样

62帧内没有发现预测前景落到图集视锥外；因此首先扩大atlas覆盖范围缺乏依据。更值得验证的是混合期望深度、遮挡层次与侧光足迹。

候选包括：在混合深度像素用两层接收点；记录更多透射深度信息；按接收像素的世界足迹选择金字塔尺度；掠射角时用局部/级联或变形图集提高有效分辨率。稀疏光线追踪可作为未来可见度诊断参考，不建议第一步更换整个渲染后端。

先对Translucent侧光长阴影和Lego/Drums交叠区域做冻结几何的受控验证，再做联合优化验证；明确区分几何改善与可见度改善。直接将512²升为1024²会使图集像素和相关缓冲约增至4倍，但总训练时间不一定4倍。双层接收点会增加着色成本。只有质量收益在统一时间/显存比较下成立才保留。

## 6. 验证设计与停止条件

1. **先修口径。** 未来正式比较统一GT生成、alpha重采样、显示变换及指标；本轮已确认这些差异不改变PSNR排名。原始test标定保持主协议。
2. **先分离原因。** 几何、分支、反射瓣、atlas按上述顺序分别测试；不一次合并多个改动，否则无法归因。
3. **训练预算单独验证。** 30k与100k需要各自预先固定学习率及细化日程；同时报告时间、显存、最终点数。单纯从已衰减且停止增密的30k权重续训，不等于合理的100k对照。
4. **选型只用训练内部留出。** 固定相机/灯组分割和接收规则，避免只优化已看过的test失败图。现有test已参与研发分析，后续应如实披露并增加独立场景/灯位证据。
5. **保留优势场景。** 任何候选都要检查FurBall、bunny/dragon/candle及真实场景的回退，不能靠牺牲SSS或更改测试相机缩小困难场景差距。
6. **稳定性与SOTA证据。** 小面板有效后，再固定方案运行18场景至少3种子，与SSD-GS/GS³/RNG及Stoch3DGS作可比验证，按任务补充SSS-GS/BiGS或解释排除理由。真正留出灯组需让baseline使用完全相同的fit/val集合。

作为优先级的算术参考：若仅Lego和Drums各恢复2 dB、其余场景不变，18场景均值增加0.2222 dB，足以跨过当前约0.206 dB的SSD-GS总均值差距。这**不是效果预测**，也不足以单独证明SOTA。

## 7. 当前推荐

优先做P0-A与P0-B各自的小规模因果验证，再考虑高光表示和图集升级。现有LiSA传输机制在多种SSS场景有收益，没有充分证据支持直接删除传输、扩大所有网络、扩大全部atlas或统一增加高斯到1M。
