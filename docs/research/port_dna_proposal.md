# PORT-DNA-2DGS：由照片学习分布式神经材质

## 问题与假设

目标是从多视角、已知点光源的照片同时拟合显式2DGS表面与可重光照神经材质。
透明/半透明物体的外观包含非局部散射，仅用局部BRDF不能表达全部效果。
8DNA把这类散射写成独立能量与条件概率分布的乘积。我们的研究假设是：
把这一分解绑定到2DGS表面，限制传输为非负、归一化、对光强线性的算子，
能够提供比自由RGB回归更清晰的材质表示，并在没有几何教师的条件下重光照。
“表示更受约束”不自动意味着图像指标更好，必须用实验检验。

## 方法

1. **表面载体**：有位置、切向尺度、朝向、透明度的2D Gaussian disks。
   多视角训练轮廓构造占据概率表面并采样初始disk。没有SDF、预训练法线/深度、
   旧模型几何。随后仅由RGB、轮廓、渲染深度—法线自一致性和深度畸变优化。
2. **局部直接材质**：每个disk存储漫反射颜色、双叶GGX参数以及有界着色法线修正。
   尖锐直接反射按解析公式计算，避免神经间接分布同时承担全部高频高光。
3. **非局部神经材质**：
   `F_indirect = A(x_o,w_o) × P(x_i,w_i | x_o,w_o)`。
   通过32个分量构造分布；每个分量在全部源surfels上归一化空间概率，
   在单位球上用归一化vMF表示入射方向。出射位置、视角与材质特征预测RGB混合权重；
   独立网络输出RGB能量。因而RGB各通道的联合入射分布总质量均为1。
4. **近场重光照**：对每个源表面点计算到当前点光源的方向、距离平方衰减与阴影，
   先按条件分布汇总，再乘出射能量并与直接反射相加。源位置没有被积分掉，
   不把点光源退化成统一远场方向。最后通过2DGS alpha与相机观察变换得到照片。
5. **图像分布训练**：RGB/SSIM决定图像拟合与能量；将每个颜色通道在图像内归一化，
   增加目标到预测的空间KL损失，约束能量落在何处。它是图像边缘分布的监督，
   并非8DNA原文的真实路径吞吐量加权NLL。

## 与8DNA的对应和区别

| 8DNA | 本方法 |
| --- | --- |
| 已知几何、材质，离线路径追踪烘焙资产 | 未知材质与几何，从真实照片联合拟合 |
| 连续8D边界传输 | 2DGS表面离散积分近似8D传输 |
| RGB自回归有理二次样条流 | RGB混合权重＋表面空间概率＋vMF方向密度 |
| 路径样本加权NLL与能量回归 | 渲染RGB/SSIM＋图像边缘分布KL |
| 保留解析直接散射 | 保留解析双叶GGX直接反射 |
| 原资产形状已知 | 轮廓初始化与2DGS自身几何一致性，无教师 |

这是受8DNA启发的新逆渲染适配，不宣称复现其全部方法、训练方差收益或论文质量。
[原文](https://arxiv.org/html/2604.25129v1) · [官方代码](https://github.com/lwwu2/8dna26)

## 首轮实验与判断标准

Cat/Pixiu分别fresh30000步，512px，40000 surfels；全官方训练集522/562张，
最终全部测试66/71张。比较PSNR、SSIM、LPIPS与原始图像/固定高光裁剪，报告
训练时间、显存和轮廓误差。旧方法有不同几何监督和计算预算，只作实际性能参考。
不依据最终test调参；不把训练拟合或更好的PSNR当作真实几何恢复。

本轮能回答“这种受约束神经材质适配是否可训练，在两个场景上表现怎样”。
尚不能单独归因32分量、归一化、图像KL或几何初值的贡献；需要后续受控消融。
稀疏、关联的视角与灯光也不足以辨识唯一物理传输。该方法不强制互易性，
直接＋间接总能量未保证全局守恒，混合分布存在低秩近似，细小高光仍是风险点。
