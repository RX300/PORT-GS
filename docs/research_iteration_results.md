# 空间传输改进实验

本轮仍未证明 SOTA。先使用原始 train 内的光照分组验证选择研究方向，再对候选按原预算完整训练。三个指定场景仍是开发面板，不代替完整数据集独立评估。

## Bunny：同种子、同 30k 步内部验证

449 帧拟合、全部 51 帧内部验证，256px；下表前四行是训练器未量化验证值。

| 方法 | PSNR ↑ | SSIM ↑ | 最终高斯数 | 训练秒数 |
| --- | ---: | ---: | ---: | ---: |
| 原全局配对传输 | 33.7484 | 0.978402 | 15608 | 475.2 |
| 空间基 L2 归一化 | 33.7466 | 0.978134 | 15429 | 492.9 |
| 局部响应去掉视角输入 | 31.6799 | 0.968716 | 8802 | 466.9 |
| 空间局部传输 | 34.7011 | 0.979080 | 17402 | 454.2 |
| 空间局部传输 + Gaussian 坐标系局部响应 | **35.7611** | **0.981356** | 19916 | 522.6 |

同一量化协议补齐感知指标：

| 方法 | PSNR ↑ | SSIM ↑ | 标准 LPIPS ↓ | 参考约定 LPIPS[0,1] ↓ |
| --- | ---: | ---: | ---: | ---: |
| 原版 | 33.747275 | 0.978308 | 0.040222 | 0.031836 |
| 空间局部传输 | 34.699591 | 0.978888 | 0.035092 | 0.027852 |
| 加 Gaussian 坐标系 | **35.759663** | **0.981223** | **0.032950** | **0.026339** |

PSNR 改善 46/51 帧，中位改善 0.9780 dB；LPIPS 改善 45/51 帧。SSIM 仅改善 27/51 帧，结构细节收益较弱。

## 失败原因的证据

- 原版 Bunny 非局部贡献约 1e-18；归一化后仍几乎没有可见贡献，说明共同幅度退化不是充分原因。
- 新空间传输冻结权重后关闭，量化 PSNR 从 34.6996 降到 29.9333，支路确实参与预测。这个 4.77 dB 消融差不是同预算重训收益；后者为 0.95 dB。
- 去除局部视角自由度导致整体退化，不能简单采用纯漫反射模型。
- Cat 有拟合不足和泛化落差。相机残差与大高斯 footprint 有一定证据，但不足以单独解释首轮 8.34 dB 测试差距。详见 failure_analysis.md。

## 后续对照状态

- Cat 两组 30k 已完成。全部内部验证的量化 PSNR/SSIM/标准 LPIPS：原版 **20.061474 / 0.753408 / 0.270712**，候选 **21.699086 / 0.770378 / 0.255818**。PSNR +1.637611 dB，三项均改善；这不是原始 test 指标。候选训练 1725.38 s、318381 个高斯；原版 1359.63 s、330018 个高斯。
- Cat fit32 PSNR 23.4306 → 24.4873；验证也同步改善，但仍明显拟合不足。冻结候选关闭空间支路只下降 0.1460 dB，原版下降 0.6061 dB；不能把同预算全部收益直接解释成最终非局部辐射的贡献。毛发细节和轮廓误差仍明显，几何/优化影响有待进一步分离。
- Bunny 候选完整 train、固定 60k 最后 checkpoint 已完成，全部原始 test 500 帧：**36.631377 / 0.983765 / 标准 LPIPS 0.029491 / LPIPS[0,1] 0.023296**。原版同协议为 36.281493 / 0.983080 / 标准 LPIPS 0.031156 / LPIPS[0,1] 0.024851；PSNR 提升 0.349884 dB，三项指标均改善。SSD 本地参考为 38.480034 / 0.989095 / LPIPS[0,1] 0.014756，新版 PSNR 仍低 1.848657 dB，未达到 SOTA。训练耗时 961.68 s，27772 个高斯。没有评价中间 checkpoint 来选择测试最佳值。
- 内部验证的 +0.95 dB 在完整 test 上仅保留 +0.35 dB，提示角度/视角泛化仍是待解决问题。下一项训练内控制检验使用 Gaussian 自身旋转坐标编码局部光照与视角，不增加参数，不把椭球坐标轴称作已知表面法线。
- AnisoMetal 本轮尚未换用候选，不能宣称三个场景都已改善。

原始对照和逐帧变化见 runs/research_iteration_summary.json；所有检查点、失败实验及日志保留。无测试期拟合、位姿校准或 GT 掩码修改预测。


## 继续排查

Gaussian 坐标系局部响应不增加参数，用高斯 quaternion 的逆旋转编码光照/视角，再使用原 PE 和 half-vector 网络；局部框架不等同于已知物理法线。该版本 30k 内部验证较仅空间局部传输提高 1.0601 dB，完整 train 60k 的测试结果已列于下方。

Cat 共享内参几何诊断失败：全六对拟合得到焦距尺度 1.2576、主点 y 偏移 -240.99px，且留一对验证四对退化。未应用这些参数。现采用已有训练相机优化作受控实验，仅优化 fit 的位姿；验证始终使用原始相机，避免按验证图像校正预测。


## Bunny 完整 train / 全量 test 进展

固定 seed 0、60k 步、256px，500 train / 500 test，最后 checkpoint，不做测试 checkpoint 选择。LPIPS 列使用单独标记的参考 [0,1] 约定：

| 模型 | PSNR ↑ | SSIM ↑ | LPIPS[0,1] ↓ |
| --- | ---: | ---: | ---: |
| 原版 | 36.281493 | 0.983080 | 0.024851 |
| 空间局部传输 | 36.631377 | 0.983765 | 0.023296 |
| 加 Gaussian 坐标系 | 38.010903 | 0.986550 | 0.019802 |
| 再匹配 PNG 合成顺序 | **38.798491** | **0.987675** | **0.018013** |
| SSD 本地参考 | 38.480034 | 0.989095 | 0.014756 |
| SSD 论文表值 | 37.296000 | 0.986100 | 0.017300 |

Gaussian 坐标系版本（未改变合成顺序）的标准 LPIPS 为 0.025397，训练 1057.40 s、32204 点。相对原版 PSNR +1.729410 dB，距离 SSD 仍差 0.469131 dB，SSIM 和 LPIPS 也仍落后，未达到 SOTA。

下一项只在 train 内重训比较 PNG 的 alpha/gamma 成像顺序。模型预测的 alpha 用于预测合成；GT alpha 仅保留原训练监督和 target_image，绝不用于遮住预测误差。HDR 成像顺序不改。此前冻结权重改合成顺序变差不能替代这项重训对照。

论文列取自已整理的 docs/baseline_metrics.json，仅指标参照，完整协议未审计。当前 Bunny Gaussian-frame 模型高于论文 PSNR/SSIM，但 LPIPS 仍落后；对更高的本地结果也未全面超越，不能改用较低参考来宣称整体 SOTA。


### Cat 位姿对照结论

30k 原始相机验证：位姿优化版 21.414114 / 0.752265 / 标准 LPIPS 0.224364 / LPIPS[0,1] 0.197504。相对固定相机的空间局部传输，PSNR -0.285 dB、SSIM -0.0181，但 LPIPS 明显改善，毛发视觉更清晰。这是取舍，不默认采用。

同一组训练匹配点、不重新估计 F：拟合相机的六对 Sampson 中位残差为 0.170、0.268、0.331、2.392、0.500、0.411 px，均低于原始相机。这支持训练几何一致性改善，但不证明原始验证相机已一致。共享光轴旋转的另一个 CPU 拟合触及约束边界、留对验证不稳定，也未应用。

### PNG 成像对照

Bunny 相同 30k 训练内验证：量化 36.352976 / 0.981323 / 标准 LPIPS 0.032264，较 Gaussian-frame 对照 PSNR +0.593313 dB、标准 LPIPS略改善；参考 LPIPS[0,1] 0.026849，反而略差于 0.026339。边界区域 MSE 0.001625→0.001224、内部 MSE 0.001395→0.001215；预测 alpha L1 0.002967→0.001727。完整 train 60k 对照已完成，见后文；目标图像及评分保持不变。


## 最新结果与在途任务

PNG 合成版完整 60k、全部 test 500 帧：**38.798491 / 0.987675 / 标准 LPIPS 0.023148 / LPIPS[0,1] 0.018013**。相对原版 PSNR **+2.516998 dB**；相对 SSD 本地参考 PSNR **+0.318457 dB**，但 SSIM **-0.001420**、LPIPS[0,1] **+0.003257**。因此仅 PSNR 超过本地参考，不能称为全面 SOTA。训练 1140.86 s，33600 高斯，未改变目标图像或评估帧。

AnisoMetal 两组 10k 内部验证（全部 225 帧）：旧版 24.240402 / 0.935877 / 标准 LPIPS 0.061020；候选 26.016436 / 0.933557 / 0.070578。PSNR +1.776034 dB，但 SSIM 和 LPIPS 退化；这只是短期筛查，不代表正式测试结果或完整预算趋势。

已启动统一候选的 Cat 与 AnisoMetal 完整 train 100k/512px，固定原相机；Bunny 复用上述完整结果。仍只覆盖三类第一个场景，不扩展其余场景。执行入口为 `benchmark.py --candidate`，批次自行评价完整 test 并写回 [候选对照](candidate_comparison.md)；旧版对照文件保留。长训练由 Luna 监控。

候选协议逐字段审计见 runs/candidate_protocol_audit.json：除三个方法开关及输出路径外，与各场景旧版完整实验共同配置一致；fit 列表逐项覆盖完整 train，未用已训练的全 train checkpoint 初始化任何内层验证实验。
