# PORT-GS 研究方案

日期：2026-09-06。当前未达到 SOTA。三场景首轮正式对照发现 Cat 落差大、Bunny 非局部分支坍缩，当前候选采用空间局部正值传输、Gaussian 坐标系局部角度编码及匹配 PNG 目标的预测 alpha 合成。Bunny 完整测试达到 38.7985 dB，超过本地 SSD 参考 PSNR 0.3185 dB，但 SSIM/LPIPS 仍落后。Cat/AnisoMetal 的候选完整对照在途。失败实验及证据见 [失败分析](failure_analysis.md)。下文原始配对核保留作为旧版对照设计。

## 当前候选：空间局部传输与局部角度响应分工

保留每个 Gaussian 的局部神经角度响应，空间传输改为可学习几何中心/宽度的 partition-of-unity：

    F_ir = softmax_r(-||x_i-a_r||² / (2*l_r²))
    E_r  = sum_j(m_j*F_jr*incident_j) / sum_j(m_j*F_jr)
    extra_i = sum_r(F_ir*E_r*softplus(strength_r))

incident 包含给定灯光强度、距离平方衰减和几何遮挡。F 不依赖光强、测试帧或视角，源端使用全部 Gaussian 的面积近似权重 m。空间中心与尺度训练学习，局部网络保留视角依赖以处理反射。连续像素查询复用全源照度汇聚，绝不将查询像素当作新光源。

实现选项为 `--localized-ports`。Bunny 同种子、同 30k 步、同原 train 内 449/51 光照划分的量化验证：旧版 33.7473 / 0.978308 / LPIPS 0.040222；候选 34.6996 / 0.978888 / 0.035092。冻结候选权重去掉空间支路，PSNR 为 29.9333；实际同预算重训收益为 0.9523 dB，不能把消融下降当成重训收益。

这说明空间局部性是一个有实验支持的方向，但仅一场景单种子、没有独立全数据集验证，不构成 SOTA 或新颖性证明。Cat 同预算内部验证 PSNR 20.0615 → 21.6991 dB，LPIPS 0.27071 → 0.25582；Bunny 完整 train 60k/test 500 帧为 36.6314 dB，相对旧版提高 0.3499 dB，但仍低于 SSD 本地参考 1.8487 dB。

## 1. 要解决的问题

目标是多视角、已知点光源的 OLAT 采集：由训练相机/光源组合重建静态 3D Gaussian 场景，在未见相机或光源下合成图像。该设置不能直接与未知环境光下的 TensoIR 榜单混为一谈。

研究假设：对毛绒、半透明物体和显著互反射区域，把输出位置与入射位置绑定在同一个 Gaussian 上，会迫使局部角度函数间接记忆空间传输。显式学习不同位置之间的传输联系，可能更有效地泛化到未见光照。高频反射则保留独立的局部角度容量，避免全部响应被低秩表示平滑掉。

这是需要消融验证的假设，并非已证明的现有方法通病。单凭命名或物理解释不足以认定新颖性。

## 2. 表示：渲染位置与光的进入位置分开

每个 Gaussian 保留标准中心、协方差、透明度，以及一个小型外观特征 z_i（初值维度 16）。几何/透明度不依赖输入光强，不为测试光源建立 embedding。

使用两部分传输核：

\[
K_{ij}(\omega_o,\omega_l)=\delta_{ij}k_i(\omega_o,\omega_l)
+\sum_{r=1}^{R}s_r\,[u_{ir}(\omega_o)v_{jr}(\omega_l)
+v_{ir}(\omega_o)u_{jr}(\omega_l)].
\]

- i 是出射 Gaussian，j 是入射 Gaussian。
- 第一项 k_i 是局部、高频的角度响应，用共享小 MLP 加 z_i 表示。
- 第二项是非局部传输，初始 R=16。每一对 u/v 对应两个可学习的空间—方向支持域；系数 s_r、u、v 均非负，RGB 独立。
- 采用固定参数量的连续坐标/方向解码，不用光源编号、相机编号或图像编号查表。

局部核可用

\[
k_i(a,b)=\tfrac12[\operatorname{softplus} f_\theta(z_i,a,b)
+\operatorname{softplus} f_\theta(z_i,b,a)]
\]

实现交换对称。方向编码保留高频输入，使用两个隐层、宽 64 的共享网络作为起点。先测速度，不预先写自定义 CUDA 内核。

实现还提供 `--asymmetric-local` 控制。局部颜色响应中的方向交换对称不等于
BRDF 互易：入射余弦和投影测度可能使整体的 cos-weighted response 不对称，因而
不能把这一选项的对比解释成 BRDF 互易性检验。

u/v 使用低阶方向特征与可学习球面 Gaussian 的紧凑组合，并乘连续空间支持权重。空间权重由位置和 z_i 决定；不引入第二套独立几何模型。成对形式 UV^T+VU^T 不要求 U=V，避免把核不必要地限制成正半定矩阵。**互易不等于正半定**。

有效采样权重 w_j 必须写入离散化：建议由 Gaussian 的空间尺度与密度导出正权重并在当前支持上归一化。它是有效体积/传输采样约定，不是已知真实表面积；需做密度变化敏感性实验。几何 densify 后应重新计算，不能使“复制更多点”自动产生更多光能。

当前默认 `--transport-measure area` 使用近似面积权重；它在薄片极限比体积权重
更稳定，但尚未证明对 Gaussian split 具有 exact split-invariance，也不构成能量守恒
保证。`volume` 仅作为同条件消融。

## 3. 前向计算

对于位置为 l 的点光源，在每个入射位置 j 计算

\[
e_j(l)=V_j(l)\,I_l/\|l-x_j\|^2.
\]

I_l 是数据协议给定的线性光强，V_j 由当前 Gaussian 几何产生透射率提示。余弦、投影面积及散射相函数的约定由核/采样测度承担，不能在输入与核中重复乘入。

将光照投影成小向量：

\[
a_r(l)=\sum_j w_jv_{jr}(\omega_{jl})e_j(l),\quad
b_r(l)=\sum_j w_ju_{jr}(\omega_{jl})e_j(l).
\]

每个出射 Gaussian 的线性颜色为

\[
c_i(\omega_o,l)=k_i(\omega_o,\omega_{il})e_i(l)
+\sum_r s_r[u_{ir}(\omega_o)a_r(l)+v_{ir}(\omega_o)b_r(l)].
\]

再对 c_i 做标准 Gaussian 光栅化。局部项的对角权重吸收到 k_i 中；讨论严格的核对称性时必须恢复统一的加权坐标。

光在 j 处进入、i 处出射，因此非局部项使用 j 到灯的距离和可见性，**不能把最终全部颜色再次乘 i 到灯的可见性**。相机遮挡由光栅化处理。这使阴影中的 i 可以接收从受光 j 传来的辐射。

初版 V 使用现有 Gaussian 光栅化从灯位置形成的深度/透射率提示。当前实现采用
一个从灯位置拟合的外部光源透视视锥，并断言所有 Gaussian 的 3-sigma 支持都在
灯相机前方；该单视锥合同取代了原计划的六面视锥。它仍是近似可见性，支持违反
合同就停止，不能用部分视锥伪装完整覆盖。自遮挡偏移按场景尺度固定并记录，
第一版不增加学习式阴影修复网络。

核心传输计算为 O(NR)，无需 N×N 稠密矩阵，也无需逐帧迭代求解多次反弹。光照投影在同一光源的不同相机间可复用；几何或传输参数更新后必须重算。首先直接计算，不建立跨训练步骤缓存系统。

## 4. 可以保证什么，不能保证什么

**可以通过结构保证：**参数固定时，物体前景辐射对光强线性；输入光强为零时输出前景辐射为零；非负输入产生非负输出；定义在统一离散测度下的有效核交换两个端点时对称。

**不能据此宣称：**恢复了唯一的真实 BRDF/BSSRDF；完整 Gaussian alpha 合成严格满足 Helmholtz 互易；在任意几何和折射率下严格能量守恒；能正确渲染任意材质编辑或物体移动。相机 alpha 合成和灯侧可见性近似未必互为伴随，不能通过交换相机/光源 RGB 图直接做“互易真值”。

初版仅为非负有效传输，不把 softplus 或低秩分解称作能量守恒。按固定角度/空间求积可增加能量超限惩罚，但惩罚只覆盖被采样方向，且真实表面积未知；不能把这一项作为严格物理保证。

线性只对线性辐射成立。sRGB 编码、tone mapping、clipping 后的图像不满足线性。白色背景下整体图像还含固定背景项，必须在前景辐射上检验线性。

## 5. 为什么值得试，以及创新边界

潜在贡献不是“3DGS + MLP”“互易性”或“全局光照”，而是**可分离的成对空间端点核、局部高频通道与跨位置光照投影的联合表示**。它把复杂传输压缩为可直接从 OLAT 观测学习的输入—输出算子，不声称求解内部每次反弹。

| 相关工作 | 已有能力 | 本方案必须证明的区别 |
|---|---|---|
| [RNG, CVPR 2025](https://openaccess.thecvf.com/content/CVPR2025/papers/Fan_RNG_Relightable_Neural_Gaussians_CVPR_2025_paper.pdf) | 在 Gaussian 上学习视角/光照条件外观 | 与等容量局部条件函数相比，显式跨位置投影是否改善未见光照 |
| [BiGS, 3DV 2025](https://arxiv.org/abs/2408.13370) | 双向散射 Gaussian；不能把互易性本身当新贡献 | 成对空间端点而非仅方向双向展开的收益 |
| [OLAT Gaussians, SA 2024](https://musinghead.github.io/projects/olat_gaussians/) | 学习入射照明和散射，适配多类材料 | 必须排除只是重命名其局部因子分解的可能性 |
| [PRTGS](https://arxiv.org/abs/2408.03538) | 高斯预计算光传输 | 从观测学习空间低秩核的准确性/成本权衡 |
| [RadiosityGS, SA 2025](https://raymondjiangkw.github.io/radiositygs.github.io/) | 半透明 Gaussian surfel 上可微全局传输求解 | 有效端点算子与物理求解器的质量、光照泛化及训练成本差异 |

以上为初步相关性核查，不是穷尽文献的“首次提出”声明。SSD-GS 只作为结果参照，不分析或复现其架构。

## 6. 风险与停止条件

1. **低秩欠拟合：**尖锐镜面和焦散可能需要很高秩。局部高频通道缓解部分问题；若 R=16→32 仍只改善训练、不改善验证，停止扩宽。
2. **空间混光：**非局部核可能在不相连部件间漏光。观察受光位置变化与暗区响应，并与删除非局部项比较。不能用测试场景专用 mask 修饰输出。
3. **表示不唯一：**u/v 可重新缩放且互相补偿；用简单范数正则即可。不能把单个模式解释成真实光子路径。
4. **几何歧义：**运输核可能掩盖错误几何。用训练 mask 的 silhouette 约束和纯局部控制实验检查；不用 GT normals、mesh 或材质辅助训练。
5. **可见性误差：**体积透明度、光栅化阴影贴图与真实透射不等价。若伪影主要由 V 造成，先解决几何/可见性，不能无证据继续增加模型模块。
6. **无可测增益：**匹配参数量、训练预算与数据划分后，若跨位置项未带来稳定验证收益，则核心假设失败，应记录结果并停止该方向的大规模训练。

## 7. 最小实现范围

只需 data.py、gaussians.py、transport.py、renderer.py、train.py、evaluate.py。使用原生 gsplat API，独立实现本方案；不继承任何 SSD-GS 训练器或 checkpoint。暂不引入 mesh、SDF、扩散先验、外部预训练材质模型、全局路径追踪器、服务化调度、版本化缓存或复杂插件架构。

阶段 A：先用 train 图像建立几何和局部重光照模型，约 5K 步验证损失下降、数据坐标和光强约定。

阶段 B：固定几何，加入成对非局部核，与相同容量的局部模型分别跑到 20K 步。至少在一个合成和一个真实场景做未见光照验证。

阶段 C：若假设成立，低学习率联合调整几何；光栅化、角度函数与传输统一优化。完整基准匹配规定训练预算，checkpoint 选择只依据训练内验证集。

这些步数是计划，不是已测得收敛所需步数。详细实验门槛见 experiment_protocol.md。

### 当前局部空间核的代数约束

写为 K_ij = sum_r(F_ir F_jr s_r / Z_r)，Z_r = sum_j(m_j F_jr)，空间核本身对 i/j 对称。单位强度时，T_ij = K_ij m_j 满足每行和为 1，并满足 m_i T_ij = m_j T_ji；对应常量照度保持与面积近似权重下的平衡。CPU 测试验证了这些恒等式。学习的 RGB 强度、局部反射、阴影近似及 Gaussian 光栅化仍使它不能被称为完整成像系统的物理互易/能量守恒证明。
