Real/GS3 明确提供点光位置和 RGB 强度；SSS 的光源位置已知，强度/曝光/背景约定尚须核实。不得在强度缺失时悄悄使用任意常数，再声称与论文协议等价。

原始 `points3d.ply` 带 normals 和 colors，但来源尚不明确。默认不使用这些字段或点坐标初始化，先用随机初始化。只有证实点云仅由允许的训练图像生成、且对照方法同样可用时，才考虑使用训练 SfM 点云。文件存在不等于可用于训练。

## 2. 验证和测试隔离

- 调参只访问 train 和经审计可用的 val；test 图像不参与训练、早停、超参选择、曝光校正、裁剪或色彩校准。
- 没有合格 val 时，从 train 元数据划分约 10% 的光源方向组作 light-held-out 验证。空间邻近的同一灯位归在一起，不只随机留几张图片；保存具体列表和划分规则。
- 另划训练内 camera-held-out 诊断组。需要同时测新相机和新灯时，从训练拟合集剔除两类保留组的并集，分别报告各类验证条件，不能把“新组合”误报为“新方向”。
- 仅用训练元数据确定分组。SSS-GS 原有 val 若与 train 相机/灯位重复，需按组合分组重新构建开发划分，并记录这一事实。
- 最终配置冻结后，可用全部官方 train 重新训练，并按固定步数取 checkpoint；正式 test 统一运行一次。报告所有预先指定场景和种子，不能在 test 上多轮选模型。
- 当前读取 SSD-GS 已有分数属于确定比较目标，不将其逐视图误差用于新模型训练或自适应选样。

官方 test 即使有重复，也按统一官方记录列表复现对照；同时补充 unique-image / unique-camera-light 统计。不能只给新方法去重后与原始加权 baseline 比较。若发现训练与测试中有相同图像/采集组合，必须额外构建无交集协议并对所有方法同样评估；不能将污染划分上的提升解释为未见光照泛化。

## 3. 评价必须对齐的细节

正式比较前写明图像路径列表、分辨率、颜色空间、曝光/光强单位、背景、mask、SSIM 实现与窗口、LPIPS 网络/版本/输入范围、PSNR 聚合方式。当前仅核对了 SSD 的输出 JSON 和论文表格，未读取其评价代码，因此这些细节仍有未核实项，不能现在称为严格等协议复现。

PNG 不一律等同 sRGB，EXR 也不自动等同已经正确曝光的物理辐射。先查数据说明与文件元数据。若协议明确使用 sRGB，按规定解码；有饱和区域不能通过逆 gamma 恢复失去的 HDR 信息。

主表按每图像计算 PSNR/SSIM/LPIPS、在场景内按协议平均，再对场景做宏平均。保留逐场景结果；不同数据集各自报告，不把 18 场景混成唯一分数。mask/白背景可能影响分数，所以 foreground 指标可作补充，不能代替官方主指标。

禁止测试时针对 GT 求 exposure、white balance、颜色矩阵、对齐、mask 边界或图片残差。若某个原基准官方允许特定校准，应单列该轨道，所有方法同样处理；本方案主要报告无测试 GT 校准的轨道。

光源混合/光强缩放只在确认线性辐射且使用训练数据时构建辅助样本。多个光源相加不计为新独立观测，也不将网络自身的线性恒等式作为额外泛化证据。

## 4. 第一轮只检验核心假设

预先选 GS3 Translucent 和 Real Pixiu 作为开发场景，分别覆盖合成与真实采集。初版先跑一个场景的短 smoke，再开始两张卡并行；这些场景仍只是开发集，不代表全榜表现。

| 实验 | 目的 |
|---|---|
| L：纯局部条件核，标准几何可见性 | 从头实现的内部控制组 |
| P：局部核 + PORT 成对跨位置核 | 检验主要贡献 |
| L-wide：增加局部容量，匹配 P 的参数量/预算 | 排除单纯参数量增加 |
| P-local：同样端点特征但禁止 j≠i 空间传输 | 排除只是换一种局部角度参数化 |

先 L/P 各到 20K 步。如果看不到验证收益，不直接启动剩余 16 个场景。通过后才做 L-wide/P-local，并补一个预先指定的高频场景 AnisoMetal，检查局部高频路径能否保持尖锐反射。

进入完整基准的工程门槛：两个开发场景的 light-held-out 验证宏平均至少提升 0.3 dB，LPIPS 不恶化，训练耗时增加控制在约 1.5 倍以内；之后必须在至少三个随机种子下确认收益方向一致。阈值只是节省实验成本的选择，不是统计显著性的替代。

核心消融还包括：R=8/16/32；非对称与成对对称核；去掉局部高频分支；固定几何与联合几何；不同采样密度。按观察到的失败模式依次做，不预先遍历所有组合。

## 5. 损失和训练选择

先使用简单图像 L1 + 小权重 DSSIM；如果辐射单位已明确，加入线性域拟合，但避免亮区完全支配误差。mask 仅用允许的训练 alpha；少量 feature 范数和几何正则足够。

不默认叠加 LPIPS 训练损失、法线先验、扩散监督、多阶段蒸馏和大量手工正则。新增项必须对应已经观察到的失败，并单独消融。

Real/GS3 完整训练以现有最终 100K 结果为预算参照；SSS 以 60K 为参照，同时报告 GPU-hours 和训练图像访问量。相同 iteration 不自动等于相同算力，应同时给出固定算力比较。开发用 20K 分数不与最终 100K/60K 分数直接宣称胜负。

## 6. SOTA 判定

比较目标同时包含 SSD-GS 的论文报告与本地结果，不能只超过较弱的一套结果就宣布超过 SSD-GS。

数值目标：在对齐协议后，比相应数据集的更强可比参照提高至少 0.5 dB，SSIM 不下降、LPIPS 不上升，并披露逐场景退步。论文宏平均对应的初步 PSNR 目标为 Real >32.61、GS3 >32.79；SSS 必须先对齐 Opt/数据处理设置，并与完整本地结果一起判断，不能简单把 38.85 当作足够目标。

“超过 SSD-GS”与“截至评估日期的 SOTA”是两种结论。后者还须纳入同数据/同监督协议下可比的 RNG、BiGS、OLAT Gaussians、RadiosityGS 等相关工作；无法对齐时标记不可直接比较，不为不同基准拼出虚假的统一排名。

最终至少三种子，报告均值和标准差。场景为主要汇总单位，视图/光源具有相关性；置信区间需按场景/光源组进行配对重采样，不能把重复图片当作独立统计样本。

## 8. 首次 SSS 正式基准里程碑（测试图像读取前固定）

在正确的 SSS train 输入合同与 Translucent 开发对照基础上，首次正式 SSS 配置统一为：

四层局部网络、half-vector、默认单尺度成对非局部 PORT、deep shadow、absgrad，

共同功率会被训练集 light_scale 归一化，不能声称它是测得的物理瓦数。

任何 test 像素或指标选择。第一轮是固定配置的 seed-0 基准；最终重复种子与
场景汇总要求仍按第6节执行。

官方 test 只用于固定模型的最终指标计算：完整帧列表、原始相机、正确世界灯光坐标，
不进行相机/曝光/颜色拟合或测试掩膜修饰。统一报告 PSNR、SSIM、标准 LPIPS，
以及单独命名的旧基线 [0,1] LPIPS 约定。无论是否达到参考分数都保留并报告结果，
不能把不达标场景从汇总移除。SSS 旧错误实验使用过官方 val 的事实保留为作废记录；
