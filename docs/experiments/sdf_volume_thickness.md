# SDF体渲染厚度：固定sharpness对照

日期：2026-09-23。状态：两组3000步训练、同16训练帧评价、首4帧邻环/小亮核审计及最终参数审计全部完成。
较薄组LPIPS改善，但PSNR、峰幅值误差、对比与precision变差，小亮核召回也下降；
未恢复准确细小高光，不晋级official-test。下一方向已选择，尚未实现或运行。

## 动机与待检验机制

前轮 [射线预算诊断](sdf_peak_budget.md) 将每步射线从512增至2048。
context的同16训练视图峰recall由.226160提高至.286642、峰对比/GT由.153857提高至.178574，
但PSNR为21.882991→21.882586，整体几乎不变，宽斑/错位仍在。
因此继续增加射线未显示整体质量收益，也没有证明训练已收敛或模型达到容量上限。

并行CPU体权重审计使用已完成的512ray context模型，在4个已见训练帧各取64峰+64邻环射线，
共512条固定射线。原sharpness147.514时，沿ray的p05–p95支撑宽度中位数约.05675个scene radius，
法线加权RMS离散中位约8.62°；乘4后约.01277/2.98°。
这种沿ray混合可能影响窄高光，但支撑宽度不等于图像平面的模糊核，也不是几何真值误差。
不重训直接改变同一头的sharpness使峰/环RGB MAE变差，属于输入与积分分布变化，
不能据此接受或否定经过适应训练的较薄表面方案。

本轮假设是：在固定SDF和同一辐射头初始化下，固定较大的CDF陡峭度、允许辐射头适应，
可能减少不同深度/法线响应的混合并改善峰的形状；也可能放大场误差、漏采样或轮廓问题。
须同时检查峰位置、幅度、邻环及全图，不能把更薄或更亮本身当作改善。

## 符号、共同源与两组设置

这里β专指代码中的 `exp(log_sharpness)`，是SDF logistic CDF的陡峭度/逆厚度控制，
不是厚度长度参数；β增大通常使有效体支撑变薄。

- Run：`sdf_volume_thickness_pilot`，仅 `Real_NRHints/Pixiu`。
- 共同原source：`runs/sdf_volume_detail_pilot/geometry_grid/Real_NRHints/Pixiu/last.pt`。
  两组从相同源各追加3000步，不继承任何已追加3k的peaks/context候选。
- 两组native512、seed0、每步2048射线，128粗区间+128重要性细采样。
- 同context采样：peak fraction=.25、peak-context fraction=.25，
  每步512峰+512非峰邻环+512前景+512定义域射线。
- 关闭hint encoding，保留已有SDF与外观细节网格，复用原学习率日程和loss权重，不重启头预热。

## 128+128积分预算的依据与限制

CPU审计中64+64→128+128曾有一条射线的RGB变化约.2377、合成法线变化42.18°。
同射线补到256+256后，128+128→256+256对应变化降到约.000307/0.280°。
但在4倍sharpness的全部512条探针射线上，128→256的RGB变化median/p95/max
仍为.00008568/.00053836/.03931，法线变化为.02871°/.13328°/9.595°。
这支持共同采用128+128作为更稳妥的受控起点，但局部尾部仍在，不能宣称积分收敛。
探针只是4个训练视图的有限峰/邻环集合，没有解析参考或全图覆盖，且所用β不是本轮geometry_grid源值。

证据保存在 `runs/sdf_peak_budget_pilot/volume_support_audit.json`，
含固定像素ids、256补查及协议；分析源码在该run的 `diagnostic_source.tar`。
本轮两终点均在相同128+128下评价。任何后续采样敏感性复核必须使用相同射线和一致协议，
只用于判断数值变化，不能代替最终图像质量评价或宣称无限采样收敛。

每组总射线为 `2048 × 3000 = 6,144,000`，每条256个体合成区间，
总计约 `1,572,864,000` 个区间位置样本（约1.573e9）。
这不是全部网络查询次数，也不含评价开销、粗采样和边界SDF额外查询的完整成本。
两组射线/区间配额相同；相对上一轮64+64，本轮每条射线的区间数翻倍。
必须记录实际训练时间和显存，不预先声称时间翻倍，也不把相对旧adaptive结果写成同成本提升。
