# Cat 优先研究：有限支撑域内的光传输

2026-09-07。目标是可推广的 3DGS relighting 表示，不以 Cat 特有的相机、材质标签或测试校正提点。原始数据不回写；SSD-GS 仅使用既有指标表，不读取其方法代码。当前未达到整体 SOTA。

## 已核实的事实

- 当前 Cat 完整模型 fit32 PSNR 24.6995，test66 为18.8050；冻结关闭空间分支后 fit32 为24.6762。训练拟合不足与泛化落差同时存在。
- 元数据读取、K缩放、c2w→CV、灯位置均通过检查；三类旋转矩阵均接近正交。Cat 特别之处是长焦、偏心主点、真实拍摄；不能擅自把主点居中。
- 宽视角训练匹配表明相机不一致。训练位姿优化能改善独立匹配点残差与毛发细节，却降低原始验证相机下的 PSNR/SSIM；共享K和共享光轴旋转诊断均不稳定，未采用。
- 2026-09-26来源更正：本地Cat与Pixiu应区分于NRHints新采集场景。对应DNL流程采用gamma2.2近似线性化，并假设没有其他主要光源；不能把新采集流程的S-log直接套在Cat上。精确本地辐射处理链仍待确认，详见nrhints_capture_audit.md。

## 研究问题与相关工作边界

一个高斯覆盖多像素时，当前模型只在其中心计算一种颜色。这会将空间外观变化压进几何增密或视角函数。候选问题是：能否显式表达有限三维支撑域内、随光照变化的辐射矩，同时约束其均值、非负性与坐标一致性？

空间变化外观本身已有工作，不能宣称为首次：
- [SVG-IR (CVPR 2025)](https://openaccess.thecvf.com/content/CVPR2025/html/Sun_SVG-IR_Spatially-Varying_Gaussian_Splatting_for_Inverse_Rendering_CVPR_2025_paper.html)
- [SVGS / SuperGaussians](https://arxiv.org/html/2411.18966)
- [RNG](https://arxiv.org/html/2409.19702v2) 已研究前向/延迟着色与混合优化，所以切换 deferred 不能当成新贡献。

本候选重点是光照条件化、三维协方差条件分布、归一化正值辐射矩及解析光栅化。是否足以构成新颖贡献仍需更完整的相关工作比较和跨场景实证；当前只是可检验的研究假设。

## 原型定义

对投影高斯：A = J W R diag(s)，S = A A^T + 0.3 I，B = A^T S^{-1}。J及其边界截断与已安装gsplat一致。令像素位移 d = p - projected_mean，则标准化三维坐标条件均值为 B d。

共享局部网络另输出每通道梯度 g = 0.25 tanh(head(hidden))。令 b = g B，局部辐射乘以下式：

    M(d) = (1 + b d)^2 / (1 + b S b^T)

M非负，关于该投影高斯自身的连续权重分布，其均值为1。g不依赖光强，保留辐射对光强的线性；零梯度恢复原表示。均值性质是遮挡合成前的单高斯性质，不是整个场景或gamma后图像能量守恒证明。

将二次式展开为六个单项式的RGB系数，共18通道，用现有gsplat做一次光栅化，再解析求值。空间传输保持原常数分量；不改变alpha、相机、GT、图像对齐或采样帧。无需新CUDA内核、网格、GT法线或屏幕空间图像网络。浮点消减误差和投影近似必须先用真实Cat协方差验证。

## 第一轮受控实验

- 原 train 的固定470 fit /52 validation，验证全部52帧；不读取test用于选择。
- 两组使用相同的训练内几何 runs/cat_localized_s0/last.pt，固定全部几何参数，重新拟合外观各10k步，512px、seed0。
- 控制为现有局部+空间传输+Gaussian坐标系+PNG成像；候选只增加辐射矩。
- 阴影和空间传输从第0步启用，因为几何已有训练内预训练。两组同配置，不将此阶段与从头10k训练混比。
- 先判断训练拟合、原相机验证、区域误差、PSNR/SSIM/LPIPS和开销。若只提高fit而降低validation，不采用。
- 相机响应应作为独立成像假设对照，不能混入上述对照后声称所有增益来自新表示，更不能在测试图像上拟合曲线。

达标条件仍包括后续联合几何优化和其余材质的负对照；本轮局部实验不能承诺 SOTA 或顶会录用。

| --- | ---: | ---: | ---: | --- |
| 控制 | 21.800246 | 0.771716 | 0.260432 | — |
| 高斯内部辐射矩 | 21.81665 | 0.77165 | 0.26029 | 约+0.016dB，无实质收益 |

辐射矩头只有约1.8–2.6%的抽样分量接近设定幅度上界；没有证据支持靠扩大幅度来追分。相机响应学得 gamma=2.1711、s=0.1013、b≈9.92e-6；不能据此宣称恢复真实相机曲线，也不能把这项有限模型/预算的负结果外推成“S-log 完全无关”。两项均不纳入当前有效主方法，不将新形式本身称作研究成功。

## 下一项核心假设：材质与方向条件化的双向空间传输

当前空间核忽略接收材质与出射方向；Cat 完整模型关闭此分支对fit32仅影响约0.023dB。下一项试验检验这种简化是否让间接光无法匹配真实多材料/方向效应，而不是继续增加像素后处理。

每个位置从共享特征头得到每通道幅度 a=sigmoid(h_a) 和向量 b=h_b/sqrt(1+||h_b||²)，对单位方向d定义：

    q(d) = a (1+b·d)^2 / (1+||b||²/3)
    E_sphere[q²] = a² (1+2||b||²+||b||⁴/5) / (1+||b||²/3)²

同一个q用于源端入射方向和接收端出射方向。将q加入现有几何空间基F，并以面积权重和解析方向二阶矩归一化：

    Z_r = sum_j m_j F_jr E_sphere[q_j²]
    K_ij(l_j,v_i) = q_i(v_i) q_j(l_j) sum_r(F_ir F_jr strength_r / Z_r)

核非负，对端点和方向同时交换时对称；材质端点共同缩放不会暗中把整个支路缩至零，支路能量仍由strength学习。这里的互易性只指这个离散核，不能宣称全系统精确能量守恒。方向积分用闭式矩，不需要增加方向采样。

零初始化新增头使a=0.5,b=0，数学上恢复现有空间核。实验不启用前两项无效控制、不改相机或GT；先用相同训练内固定几何和预算比较。它是待验证的传输建模假设，不能据此承诺新颖性或SOTA。

### Material-angular 固定几何结果（2026-09-07）

`runs/cat_material_angular_s0` 已完成10k步，使用与固定几何控制相同的470 fit/52 validation、318381个冻结Gaussian、512px和原始相机；只增加 `--material-angular-ports`，未启用辐射矩或相机响应。完整52帧验证为 PSNR **21.918029**、SSIM **0.774645**、标准 LPIPS **0.257051**（LPIPS_baseline_01 **0.236846**）。相对固定几何控制（21.800246 / 0.771716 / 0.260432）分别为 **+0.117783 dB / +0.002929 / -0.003381**，属于小幅收益，不能据此宣称 SOTA。

Fit32 诊断中，完整分支 PSNR **22.210308**，关闭 nonlocal 后 **21.362764**，差 **0.847544 dB**；这表明 nonlocal 分支确实参与拟合。结果仍只是固定几何的训练内验证，不能代替正式 test 评估或证明该核的新颖性。

## 独立诊断：几何优化的投影步幅

CPU审计见 `runs/cat_geometry_conditioning_audit.json`。三场景的 camera_extent/object_radius 分别为12.19、4.18、2.95，fx/图像宽分别为6.173、1.866、1.389。按初始位置学习率估计的名义投影步幅为0.600、0.198、0.0725像素；它不是实际初始Adam位移。

从完整训练最后一步Adam状态恢复的实际位移，经8个均匀选择的训练相机投影，p95分别为0.003514、0.001452、0.000542像素。统计仅要求中心在视锥内、opacity>0.05，不做遮挡加权。末期数值受训练历史影响，不能反推早期震荡，也不能单独归因Cat误差。

这一证据支持一个独立的训练条件诊断：从头复现 `cat_localized_s0` 的30k内部分割实验，仅将位置学习率尺度由camera改为object，保存到 `cat_localized_object_step_s0`。保持原控制其余设置，不混入新的外观模块；报告固定last的全部52帧验证结果。这属于排查几何优化条件，不作为论文研究贡献。实验已完成，结果见文末补记。
