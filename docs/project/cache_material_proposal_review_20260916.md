# PORT-GS cache / material 提案自审

日期：2026-09-16。审查对象：[研究提案](../research/cache_material_proposals_20260916.md)。
这是同一主代理在方案形成后的第二次检查，不是独立审稿人或实验复验。
本次没有修改模型、启动训练、改变已有实验配置，也没有将建议登记为已采纳架构。

## 1. 审查结论

保留两个候选：A1解耦端口两端空间支持，B1给直接光增加学习坐标系。
优先级按研究目标决定：近场非局部传输优先A1，局部金属高光优先B1。
完整物理NIRC不进入首轮，因为所需监督和渲染模块尚不具备。

两项均具备清楚的当前模型退化情形，可以设计单变量比较。
但没有任何新结果证明它们一定提高PORT-GS的PSNR、速度或材质正确性。

## 2. 主要质疑及处理

| 质疑 | 核查与处理 | 残余风险 |
| --- | --- | --- |
| A只是给现有方向端口换名字？ | 已明确当前模型本来就有源/接收位置与方向；A1唯一核心变化是输入和输出空间核不再绑定 | 低秩双端因子化属于既有思想，研究新颖性待实证 |
| A需要512²个端口连接？ | 不需要。每个模式具有一对空间支持，仍只在同一r内部用C变换方向通道 | 这种因子化仍有限秩，不能表示所有复杂路径 |
| 解耦必然改善SSS？ | 否。它只是避免用同一个宽空间核同时覆盖两端的限制 | 可能加重跨物体部位的非物理漏光，须由留出灯光判定 |
| 增加B之后提升就能证明结构有效？ | A1先保持B=4；B增大作为后续单独实验并记录成本 | 空间与角度容量、优化难度之间仍有耦合 |
| 当前方向通道就是物理入射方向？ | 否。方向基随材质特征变化，属于潜在低秩因子；已删除真实方向分箱解释 | 无路径GT时不能给每个通道赋予唯一物理意义 |
| 归一化后的算子守恒吗？ | π是源平均权重；m是代理测度，C是任意非负矩阵，像素查询也无通量积分 | 不承诺物理守恒、互易性或正确反照率 |
| a就是散射率吗？ | 源池化中a统一缩放会在分子分母抵消，且接收端另有C及a | 光照/传输/材质分解仍不可唯一辨识 |
| B与已有direction_net重复？ | 原direction_net仅影响非局部方向基；B1改变的是直接光MLP的输入坐标系 | 共享MLP本就可能隐式学会旋转，显式frame未必增加有效容量 |
| 学习frame等于获得法线和BRDF？ | 否。Q先作为外观坐标系，不强加GGX法线解释或把Gaussian轴当真值 | 真实材质编辑还需几何、辐射定标及物理验证 |
| B能保证跨视图一致？ | 每Gaussian特征静态，但像素alpha混合与期望深度依赖视角，已明确限制 | 可能需以后采用更可靠表面查询；本次未扩大实现范围 |
| B能替代整个SSS分支？ | 不能。局部方向函数没有跨位置散射自由度 | Cat毛发轮廓和遮挡仍可能由几何主导 |
| 最新文献速度和质量可以照搬？ | 不可以。工业NRC有路径追踪监督；NIV预积分漫反射；NeuMatEx有已知几何和预训练先验 | 目前只迁移结构动机，性能必须在PORT中测量 |
| cache自监督足以证明材质正确？ | 不足。两个自由分支可能共同拟合错误解；完整NIRC的估计器一致性也不等于材质可辨识 | 本次仅提供有效外观候选，不声称解决逆问题唯一性 |
| 64→512结果证实应该继续增R？ | 原实验同时改日程且只用seed0；真实场景变化小，不能建立单一因果结论 | 60k结果未完成，不能排除训练预算/优化因素 |

## 3. 公式检查

### A1回到当前模型

令输入/输出两组中心与宽度分别相等，则w_in=w_out=w。
提案中的π等于m_j a_jc w_jr / D_rc，与现有log-space source softmax后
再除RGB分母的计算相同。沿用b_in、b_out、C、a及直接光即可恢复当前方向模型。

### B1回到当前模型

令Q为单位旋转，三个方向编码和方向内积不变，其余输入也不变。
于是原直接光MLP输出不变。这为相同基模型上的局部诊断提供明确定义，
不要求先引入新的解析BRDF再把退化误差混入实验。

### 线性与非负性的范围

固定几何和参数时，每盏灯的E线性依赖其RGB强度。角度基虽非线性依赖灯方向，
但各盏灯分别求值和注入Z后再相加，仍是对光源叠加的线性映射。
不能将多盏灯合成一个平均方向再查询。

A1保持π、方向基、C和接收权重非负，因此非负光照的非局部输出非负。
B1保留原softplus直接光响应和外乘强度，故保留同样性质。
光照叠加关系适用于线性前景。背景合成是仿射操作，gamma、裁剪和显示变换不是线性操作。

这些是代数核查，不是运行新增模型的数值测试。

## 4. 对实施范围的收敛

审查后把两个候选的第一版分别收敛为一个核心变化：

- A1只拆分空间核，暂不同时引入端口间图、B=8和多尺度层级。
- B1只添加学习坐标系，暂不同时添加大材质先验和多种解析/神经材质瓣。
- 不把原非局部RGB重新当作入射irradiance，再重复乘接收端材质/直接可见性。
- 不以约束C行和或softmax得到“物理守恒”的未经证明结论。
- 不宣称小参数增量必然等于实时加速。

## 5. 验证审查

先用train内按灯方向分组的holdout，且参与固定几何诊断的基模型只能看fit子集。
不使用见过holdout的全train checkpoint，再把冻结几何上的结果称为未见灯光泛化。
初筛后应复验候选与控制的训练方差；固定模型选择后才评价官方test。

分别记录目标场景、逐灯组表现、最差视角、轮廓/阴影/高光图像，以及模型成本。
若没有多灯或新灯距GT，相应渲染只能验证一致性与稳定性，不能代替质量评价。
若改进仅出现在训练集、或通过异常非局部亮度补偿阴影错误，应停止该候选。

本次工作完成的是资料核对、基于代码的提案和自审，尚未进入实现与实验阶段。
