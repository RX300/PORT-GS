1. 复核全部结果：完整test帧数/顺序、最后权重、有限逐帧指标、失败重试、训练与测试划分、标定、分辨率、背景/gamma/量化、指标定义、初始化、训练预算与预训练依赖。
2. 生成总体18场景等权平均、三类数据各自平均、18张单场景表。报告相对各baseline的PSNR/SSIM/LPIPS差值、领先/落后场景和主要平均值贡献。跨帧统计不能冒充跨训练种子的稳定性证据。
3. 检索并实际读取截至分析时的相关论文、官方项目和代码。只用能核验的第一手来源，记录发表日期、数据范围、评价协议与可比性；优先核查相同点光源/OLAT重光照任务，而非不匹配的环境光或额外监督设置。
4. 明确区分“本地GS³/SSD-GS/RNG比较是否领先”与“是否有文献级SOTA证据”。三条baseline均值领先不足以独立证明SOTA；协议不一致或关键对照缺失时，明确结论范围与证据缺口。
5. 对主要落后场景进行证据诊断：使用已有逐帧指标、训练日志、保存图片和冻结权重，检查几何/轮廓与薄结构、高光与方向表达、阴影/图集分辨率及多尺度读取、局部/传输分解、相机标定、训练收敛与预算影响。必要时复用既有诊断入口做少量冻结模型前向分析。
6. 将结论分为已确认事实、有支持的解释和待验证假设。不能仅凭低PSNR或单张图归因，也不能把对测试GT的对齐诊断当作正式成绩。
7. 提出有优先级的改进方案：每项写清目标失败模式、对应证据、机制、最小验证设计、训练/推理成本、风险与预期取舍。只列拟议实验，不运行这些实验。
