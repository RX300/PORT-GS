## Confirmed implementation issue

**P2: fit evaluation omits learned training-camera corrections.** Training uses
`camera_offsets.correct()` in `train.py:304–307`, and saves those offsets in its
checkpoint. `evaluate.py:254–273` loads the checkpoint but directly constructs
raw samples without restoring those corrections. For a model trained with
`--optimize-cameras`, `--split fit` therefore measures performance under the
original calibration rather than the cameras actually used for fitting. This
can mislead a fit-versus-generalization diagnosis. Validation and test using
their original calibration is the intended protocol. The previous best Cat

remaining image errors. Removing this historical training option and its

## Representation limitations and hypotheses

These are observed design properties and evidence-supported hypotheses, not
confirmed unique causes of poor real-scene performance.

1. **P1: geometry and appearance can absorb each other's errors.** The current
   local MLP consumes direction encodings and free features to predict RGB
   response (`transport.py:174–229`). The previous best Cat configuration uses
   world directions. Its geometry supervision consists of RGB, weak silhouette
   loss, and feature regularization (`train.py:328–338`); the neural path has no
   explicit surface-orientation or material factorization. This flexibility can
   fit images using view-dependent appearance while retaining inaccurate or
   broad Gaussian support. Existing Cat diagnostics show about 80% of validation
   squared error inside the object, detail energy around 27% of GT, and a
   camera-contribution-weighted support radius around 22 pixels. These findings
   support addressing geometry and appearance together, while leaving camera
   calibration uncertainty explicit.

2. **P1: the additive spatial branch has weak material coupling.** Localized
   ports pool incoming irradiance and add positive RGB directly to local color
   (`transport.py:346–364`). In the active configuration the branch does not
   condition on receiver material or outgoing direction. Its detached
   opacity-times-area source weights include the complete Gaussian population
   (`transport.py:15–26`), which is a discrete quadrature approximation rather
   than measured surface area. Historical Cat fit diagnostics changed only
   about 0.023 dB when this branch was disabled. A material-angular variant
   achieved a small, separate fixed-geometry gain of about 0.118 dB. These
   results motivate a replacement but do not establish that nonlocal transport
   alone explains the remaining deficit.

3. **P2: finite-bin shadows couple visibility to broad support.** Deep shadows
   use 256-pixel maps and 64 depth bins (`renderer.py:24`), then query before the
   receiver by at least 1.5 bins or two directional standard deviations
   (`renderer.py:58–67`). This excludes nearby occluders together with the
   receiver's own contribution. It can matter for hairs, paper folds, and
   adjacent thin layers. Existing evidence does not establish that increasing
   resolution alone would improve the result. The earlier useful shadow-gradient
   change is already part of the current implementation.

## Proposed conservative exchange operator

The main agent proposes replacing additive extra radiance with a positive
exchange of incoming irradiance. For one color channel, let `m_i > 0` be the
fixed source quadrature weights, `0 < a_i < 1` the learned exchange fraction,
and `f_ir >= 0` an anchor partition with `sum_r f_ir = 1`. Define

```text
z_r = sum_j m_j a_j f_jr
u_r = sum_j m_j a_j f_jr E_j / z_r
E'_i = (1 - a_i) E_i + a_i sum_r f_ir u_r.
```

With positive softmax partitions and sigmoid exchange fractions, each `z_r`
is positive in real arithmetic. The exact formulas should be implemented
directly; added fallback denominators would change the stated operator.

### Properties verified analytically

The matrix acting on irradiance is

```text
T_ij = (1 - a_i) delta_ij
       + a_i a_j m_j sum_r f_ir f_jr / z_r.
```

It has the following properties for each color channel and each fixed geometry:

- **Positivity:** every coefficient is nonnegative.
- **Row normalization:** `sum_j T_ij = (1-a_i) + a_i sum_r f_ir = 1`.
  Constant irradiance is preserved, and every output lies between the smallest
  and largest input irradiance in that channel.
- **Weighted conservation:**
  `sum_i m_i E'_i = sum_i m_i (1-a_i) E_i + sum_r z_r u_r
  = sum_i m_i E_i`.
- **Detailed balance:** `m_i T_ij = m_j T_ji`. Equivalently, the operator is
  self-adjoint in the `m`-weighted inner product. This is the precise scope of
  the proposed mass-metric reciprocity.
- **Light-intensity linearity:** the mapping is linear when `a`, `f`, and `m`
  do not depend on illumination intensity. Zero irradiance gives zero output.
- **Bounded averaging:** the operator cannot produce channel values beyond
  the source range. Its symmetric similarity transform is the sum of a
  nonnegative diagonal matrix and a positive semidefinite low-rank matrix.
  Therefore its eigenvalues lie in `[0, 1]`.

The RGB implementation may use channel-dependent `a_ic` and `z_rc`; the proof
applies independently to each channel. Normalizing `m` to sum to one is optional
for these identities; it only fixes a convenient quadrature scale.

### Modeling risks and claim boundaries

1. **The exchange fraction is not absorption.** The operator returns all
   exchanged weighted irradiance to the system. Calling `a` an absorption
   coefficient would imply physical loss that the formula does not contain.
   Use “exchange fraction” in code and documentation.
2. **Conservation holds before receiver material response.** Multiplying
   `E'_i` by a local material/angular response, then alpha-compositing and
   applying a camera response, generally changes the conserved quantity.
   Detailed balance of `T` does not prove Helmholtz reciprocity or energy
   conservation of the complete renderer.
3. **Incident direction is compressed away by RGB pooling.** If local shading
   uses the original point-light direction after mixing, indirect irradiance
   is shaded as though it arrived from that direction. This is a compact
   learned approximation, especially limited for anisotropic/specular
   indirect transport. The method must describe that approximation explicitly.
4. **Averaging can suppress spatial variation.** Applying receiver response
   after exchange preserves that response's spatial texture, which is the
   proposed advantage over adding smooth RGB. It does not guarantee sharp
   illumination patterns or fix broad Gaussian support. Large learned `a`
   may blur illumination, and `a` tending to zero can deactivate exchange.
5. **Spatial connectivity is approximate.** A softmax anchor partition links
   all points with positive weights, including opposite sides or disconnected
   objects. Existing shadow visibility constrains direct incident light but
   does not establish source-to-receiver visibility inside this exchange.
6. **The conserved mass is representational.** Opacity-times-area Gaussian
   quadrature is not calibrated physical flux measure. It changes with
   geometry optimization and densification. Conservation applies to each
   current forward operator, not to total scene energy over training steps.
7. **This algebra alone is not a novelty claim.** The construction is a
   reversible averaging operator with a low-rank factorization. A research
   contribution would need a precise comparison to related transport methods
   and empirical evidence that this factorization helps relighting quality,
   efficiency, or generalization.

This review supports implementing the operator as one coherent, testable
replacement. It does not establish expected PSNR gains or top-conference
novelty. The next review should check the actual implementation against these
identities, data/split ownership, and the production path's simplification.

## Equivalent exchange factorization and memory layout

After the first candidate reached its point budget, the main agent identified
slow exchange evaluation. The reviewer audited the authorized replacement and
optimized only the memory layout of `exchange_irradiance`. Let
`w_ir = m_i f_ir / sum_j m_j f_jr`. The pooled irradiance is equivalently

```text
u_rc = sum_i w_ir a_ic E_ic / sum_i w_ir a_ic.
```

The common port normalization cancels between numerator and denominator.
Thus positivity, weighted conservation, detailed balance, and derivatives are
the same mathematical operator. The denominator is positive under the stated
positive exchange-fraction contract. The implementation uses direct division
and introduces no epsilon or fallback branch. It stores source weights as a
contiguous `R x N` matrix and performs softmax over the contiguous source axis.
This removes the `N x R x RGB` intermediate and the slow strided source-axis
normalization.

With the running training process paused, GPU 0 profiling used all 167,692
actual saved Cat points, 32 anchors, actual train lights 0 and 261, and exchange
fractions derived from saved features, ranging from .000543 to .802188.
The archived original function was loaded directly from
`interrupted_tensor_expansion/cat_r1_source.tar`
into memory for comparison; no second production implementation was created.
Four warm iterations preceded twelve CUDA-event measurements per operation.

| Operation | Archived implementation | Final factorization/layout |
|---|---:|---:|
| Exchange forward median | 75.648 ms | .246 ms |
| Exchange forward/backward median | 126.353 ms | .982 ms |
| Forward/backward incremental peak allocation | 334.9 MiB | 111.2 MiB |

The isolated exchange forward/backward speedup is about 129 times. This is not
an end-to-end training speedup claim. The unchanged local material network took
about 5.57 ms for its own forward/backward; shadows, rasterization, refinement,
and optimizer costs were outside this profiling scope.

Full-size float64 comparison gives relative output difference `3.40e-15` and

These reference checks support numerical improvement together with the
