## 诊断证据与解释边界

- Cat 的 32 个训练视图 PSNR 为 25.5991，测试 18.9007，既有拟合不足，也有显著泛化落差。误差平方和中内部占 72.93%、边界 18.83%、背景 8.24%。不能把主要差距归咎于边缘合成。
- Cat 六组训练图像 SIFT 审计，元数据相机的成对中位 Sampson 误差再取中位数为 0.483 像素；图像估计 F 为 0.233 像素。这提示小幅相机残差，不足以确认严重坐标系错误，更不足以单独解释 8 dB。
- Cat 灯距训练分布约 0.979–2.087，测试约 1.068–1.841；强度一致。训练抽样 PSNR 与灯距相关系数 +0.438。近场响应建模不足是待检验假设，不能据此改灯光标注。
- Bunny 训练抽样 PSNR 39.3083；关闭非局部分支后量化结果完全相同。四个训练帧的相机贡献加权非局部能量比例仅 5.96e-19–1.91e-18，确认分支坍缩。
- Bunny 深阴影点的加权局部增益约 0.657–3.902，并非极端大数。因此未支持“局部网络靠巨大增益反演可见度”的初始猜测，不采用任意局部增益截断。
- 固定权重下改变 PNG alpha/gamma 合成使 Cat/Bunny 分别降约 0.61/1.59 dB；这是敏感性测试，不能代替两种成像模型各自重新训练的比较。

证据：runs/cat_render_diagnosis/metrics.json、runs/bunny_render_diagnosis/metrics.json、runs/bunny_transport_collapse.json、runs/cat_camera_audit.json。所有新诊断仅用 train。

## 首个改进：消除空间传输基的幅度退化

原空间端点为未归一化 softplus，两个端点的共同幅度可一起缩至零。新模式对空间 logits q 使用训练几何确定的、与光源无关的面积权重 w：

    log_norm = 0.5 * logsumexp(2*q + log(w), sources)
    phi = exp(q - log_norm)

每个端点满足 sum(w*phi^2)=1。传输强度单独学习，并除以 2R 保持初始尺度与 rank 相容；不强迫非局部贡献大于零。连续像素查询复用全部源高斯的归一化量。此变更消除共同空间幅度退化，但不保证避免所有局部极小值、能量守恒或提高 PSNR。

第一轮为 bunny_small 从头训练的两个 30k 步实验：同 seed=0、同原始 train 内光照分组 fit/validation、同 256 分辨率/F32/W128/R32/4 层/half-vector/deep shadow/absgrad。每 5k 步评价全部内部验证帧。GPU 0 为旧参数化，GPU 1 为新参数化。不得从已经用过全部 train 的正式模型初始化。先判断完整内部验证 PSNR 和分支贡献，再决定后续；尚无新模式性能结论。


补充几何审计：8 个训练相机下，中心在图像内且 opacity>0.05 的 Cat Gaussian，投影 major std 的 p50/p95 为 4.62/13.37 px；Bunny 为 3.26/8.56 px。未做遮挡加权，包含内部点。相对图像边长 Bunny 反而更大，因此该统计不能单独解释 Cat 落差。原始统计见 runs/panel_splat_footprints.json。

实现已通过 CPU 加权范数、共同 logit 平移不变性、光强线性、有限梯度验证；deferred 查询源点的子集时，与完整源点着色结果一致，验证归一化不依赖查询数量。

Bunny 旧参数化 30k 对照已完成：全部 51 个内部验证帧 PSNR 33.748423（训练器未量化），量化诊断为 33.747275，关闭非局部分支仍 33.747275。Cat 也启动了同样 30k、512px、原始 train 内划分的旧参数化对照；不复用全 train 正式 checkpoint。


## 归一化实验结论：未成功

Bunny 全部 51 个内部验证帧，30k 固定最后 checkpoint：旧版 33.748423 dB / SSIM 0.978402，新版 33.746582 / 0.978134。新版量化诊断 current/no_nonlocal 为 33.746349/33.746348，分支仍几乎不起作用。不能把早期 10k 的 +0.428 dB 当成最终收益。新模式只保留为可复现实验选项，不设为默认。

因此共同尺度退化不是充分解释，空间支持、局部/非局部分解及角度泛化仍需排查。下一项 Bunny 控制为局部响应去除视角输入（保持参数数量、原 train 划分和 30k 预算），不与归一化合并。它检验视角自由度是否在近似漫反射场景中导致过拟合，不宣称适用于 AnisoMetal 或所有材质。

## 后续结构修正：空间局部的正值传输

基函数归一化无法阻止无用空间支持，且 Bunny 去除局部视角信息在 15k 仅 23.7911 dB（旧版 33.1664），不能简单采用纯视角无关局部着色。

下一项保留完整局部角度响应，替换非局部支路为几何上的局部光照混合：R 个可学习空间中心/宽度构造 F_ir = softmax_r(-||x_i-a_r||²/(2*l_r²))；每个中心汇聚带遮挡和距离衰减的源点照度 E_r = sum_j(m_j F_jr I_j) / sum_j(m_j F_jr)，再输出 sum_r(F_ir E_r softplus(s_r))。源权重在 log 域归一化，避免很小的分母。

这个结构把空间邻近性直接放进传输算子，避免用逐点特征任意指定端点幅度；局部视角响应不变。它保持非负、光强线性，零输入产生零输出，不引入测试图像或额外光源。它是对当前失败原因的结构性假设，尚不是经验证的散射物理模型；尤其源点面积近似、遮挡近似与多层表面混合仍有限制。

## Cat 宽视角复核

此前仅 5–9° 的相机对不足以排除几何标定问题。使用 control split.json 的精确 fit index 集（470 帧，validation 52 帧散布在原始序列中），挑选 6 对 20–40° 相机转角、相近灯光的图像。两对拥有 93/54 个 image-F RANSAC 内点；全部六对的 metadata-F 中位残差高于 image-F。跨对中位数为 3.687 px vs 0.0455 px。image-F 在小样本对上容易过拟合，因此不将后一数值视为绝对相机精度。

这加强了“Cat 宽视角存在几何不一致”的证据，但尚不能区分共享内参、逐相机位姿、畸变或匹配问题。下一项仅在这些 fit 图像上做共享内参的 leave-one-pair-out 几何诊断，不修改任何数据或渲染相机。正确报告为 runs/cat_camera_wide_audit.json。早先误将 fit 描述为序列前 470 帧的报告保留为 _prefix_selection.json；其选中图像经核查也全属于实际 fit，但选择规则与描述已纠正并重跑。
